# 응급의료 배정 솔버 실험

2026년 9월 13일 수행. 실제 환자·병원 데이터 및 SAVE-R 내부 알고리즘은 사용하지 않았습니다. 합성 입력에서 배정 방법을 비교하는 탐색 실험입니다.

## 파일

- `inputs.json`: 150개 조건별 관측 입력과 평가용 실제 상태. 실제 상태는 합성 정답이며 병원 실측값이 아닙니다.
- `trials.json`: 450개 평가의 환자별 배정, 실행 결과, 목적함수, 솔버 하한, 상태, 계산시간.
- `summary.json`: 30회 평균과 표본 표준편차. 각 시행을 동일 가중으로 평균합니다.
- `sensitivity.json`: 정상·과밀 조건의 시드 0~2에서 세 가지 계산 예산으로 실행한 18개 결과.
- `metadata.json`: 버전과 설정, 검증 항목.
- 루트의 `solver_experiment.py`, `solver_sensitivity.py`: 실행 코드.

## 재실행

Python 3.12.14, OR-Tools 9.15.6755로 실행했습니다. 다른 환경에서는 아래 예시처럼 작업 폴더에 의존성을 설치합니다. 패키지는 코드 파일 옆 `.solver_deps`에서 불러옵니다.

```powershell
python -m pip install --target .solver_deps ortools==9.15.6755
python solver_experiment.py

```

이 작업 환경의 실제 Python 경로는 `C:\Users\PC\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe`입니다. 실행 시 결과 JSON을 갱신합니다. 단일 작업자와 고정 시드를 사용하지만 버전·환경·실제 시간 상한에 따라 결과나 실행시간은 달라질 수 있습니다.

## 모형과 목적함수

시간은 5분 단위 정수입니다. 병원 A/B/C의 병상 용량은 2/2/1, 전문팀 용량은 1/1/0입니다. 기본 12명, 과밀 24명이며 모든 환자가 의사결정 시점에 알려져 있습니다. 전문팀 필요 확률은 0.4, 가중치는 1·2·4 중 동일 확률, 처치시간은 3~6슬롯 정수 균등, 병원별 이동시간은 1~7슬롯 정수 균등입니다. 병원별 기존 환자 1명이 2~6슬롯 점유하며 A/B의 기존 환자는 전문팀도 점유합니다. 모든 값은 가상 설정입니다.

환자 i의 병원 h 배정 여부 x(i,h)는 이진 변수이고, 미배정 u(i)도 이진 변수입니다. 합계_h x(i,h)+u(i)=1입니다. 선택된 병원에서만 시작시각 s(i,h)>=이동시간, 미선택 병원에서는 s(i,h)=0입니다. 시작은 24슬롯 이내이고, 종료가 24슬롯을 넘어도 자원을 계속 점유합니다. 선택적 구간과 누적 제약으로 병상·전문팀 동시 용량을 검사합니다.

목적함수는 `M*sum(u) + sum(weight[i]*s[i,h])`, M은 `24*sum(weight)+1`입니다. 전체 미배정 수를 먼저 줄이고 가중 시작시간을 다음으로 줄입니다. 중증군의 미배정을 최우선으로 하는 임상 정책은 아닙니다. 조기치료 순차 해를 힌트 및 목적함수 상한으로 제공하므로 관측 모형 내에서는 그 목적함수보다 악화되지 않습니다. 실제 실행 지표에는 이 보장이 적용되지 않습니다.

최근접·조기치료 순차 방식 모두 가중치 내림차순, 동률이면 환자 ID 순으로 진행하며 자원 점유를 갱신합니다. 최근접은 이동시간, 조기치료는 가능한 치료 시작시간을 먼저 최소화합니다. 모두 같은 적합성·용량·시작범위를 지킵니다.

## 불확실성 조건과 평가 규칙

1. 정상: 관측 정보와 평가 상태가 같습니다.
2. 과밀: 환자 수를 24명으로 늘립니다. 다른 조건과 동일한 환자 집합 비교가 아니라 별도 부하 조건입니다.
3. 자원 정보 지연: 기존 환자 3명의 점유 종료가 관측치보다 4슬롯 늦습니다.
4. 미반영 유입: A/B/C에 1명씩, A에 추가 1명을 더하여 각 6슬롯 점유합니다. A/B 첫 추가 환자는 t=0, C는 초기 환자 종료시점, A의 두 번째 추가 환자는 t=6부터 점유합니다. 이 외부 환자들은 배정 모듈에 보이지 않는 고정 점유이며 결과 평균에는 포함되지 않습니다. 외부 유입을 포함한 전체 환자 편익은 측정하지 않습니다.
5. 시간 오차: 신규 환자의 이동·처치 슬롯 수에 각각 1.3을 곱해 정수 올림합니다. 5분 단위 올림으로 실제 증가율은 30%보다 클 수 있습니다. 기존 점유시간은 그대로입니다.

12명 조건은 같은 시드에서 동일한 관측 입력을 사용하고 숨겨진 실제 상태만 바꿉니다. 따라서 네 조건의 CP-SAT 최적화 문제는 동일하며, 150회 실행은 독립된 최적화 문제 150개를 의미하지 않습니다. 서로 다른 관측 문제는 정상 30개와 과밀 30개입니다.

평가기에는 배정 후 실제 점유와 실제 시간을 전달합니다. 목적지는 고정하고 계획 시작시각, 가중치 내림차순, ID 순으로 처리합니다. 실제 도착 이후이며 계획시각보다 이르지 않은 최초의 가능한 시간에 치료를 시작합니다. 이는 고정 계획 지연 모형으로 실제 병원의 응급 우선순위 대기열이나 온라인 재배정 구현은 아닙니다. 외부 점유는 우선 고정하며 각 외부 환자의 대기·치료 결과는 비교하지 않습니다.

## 지표와 해석

`weighted_start`는 배정된 환자의 가중 치료 시작시간 평균(분)입니다. `mean_start`는 단순 평균, `max_start`는 시행별 최대값입니다. summary의 `max_start`는 이 최대값들의 평균입니다. 시작시간에는 이동과 병원 대기가 포함되고 문의·출동·병원 승인시간은 포함되지 않습니다.

`unassigned`는 계획 시작범위 120분 안에 배정하지 못한 인원, `late_over_120`은 배정했으나 실제 시작이 120분을 넘은 인원입니다. 미배정은 실제 사망·미수용이 아니며 120분은 임상 기준이 아닙니다. 미배정자는 시간 평균에서 제외되므로 반드시 미배정 수와 함께 읽어야 합니다.

`mean_slip`은 실제 시작과 계획 시작 차이의 단순 평균입니다. `gap`은 `(목적값-솔버 하한)/max(1,목적값)`이며 최적성 보증의 부족을 나타낼 뿐 실제 개선 가능 비율은 아닙니다.

정상 조건 조기치료 순차와 CP-SAT의 시드별 가중 평균 차이를 사용한 95% 구간은 `평균 차이 ± 2.045*차이의 표본 표준편차/sqrt(30)`입니다. 임상 일반화나 인과 추론에 사용할 수 없습니다.

## 검증

실행 코드의 검증은 작은 2환자 문제를 독립 전수열거 최적값과 비교합니다. 전문팀 불가·전체 병상 불가 조건에서 미배정을 반환하는지도 확인합니다. 모든 계획을 별도 슬롯별 검사기로 검사하고 정상 정보 재생 시 계획 지연이 0임을 확인합니다. 이 검사는 모델의 정확성을 점검하는 것이며 실제 서비스의 의료적 타당성을 검증하지 않습니다.
