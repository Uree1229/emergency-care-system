지도 실행과 오프라인 안내

저장소 루트에서 Python 3.12로 실행합니다. --reuse-data가 기존 기록을 그대로 사용하도록 합니다.

python -m simulation.viewer_server --port 18045 --reuse-data --no-browser

지도 배경에 연결되지 않으면 뷰어에서 간략지도를 선택하세요. 이 안내의 연구 사례·표는 인터넷 없이도 열립니다. 기록을 새로 생성하는 명령은 필요하지 않습니다.

02 / PAIRED CASES

개선된 환자와 늦어진 환자

아래 사례는 이미 관측한 개발 자료입니다.
전체 성과를 대신하는 대표 표본은 아닙니다.

저장된 사례를 불러오는 중입니다.

H1·W1은 현재 수용 응답과 자원으로 판단하는 연구 정책입니다. 운영 서버의 CP-SAT과 목적·모형·예산이 달라 같은 문제의 승패로 비교하지 않습니다.

03 / COHORTS KEPT SEPARATE

사례 뒤의 전체 결과

개발과 새 검증의 환자 수·성과를 합치지 않습니다.

코호트 집계를 불러오는 중입니다.

04 / LIMITS & CHECKS

시연 전에 확인할 것

기록과 실제 현장을 구분

지도 움직임은 실제 GPS·우선주행·지속 갱신 교통이 아닙니다. 병원 수용은 합성 역할 입력이며 실제 기관에 문의하지 않았습니다.

평균만으로 개선 판정하지 않기

개인 지연, 기존 성공 기록 상실과 미도착을 함께 봅니다. 제한시간 차이가 0이어도 도착과 치료 시작 성공은 다를 수 있습니다.

연구 수치를 임상 기준으로 부르지 않기

우선군 4·2·1과 30/60/120분 기준은 실험 설정입니다. 임상 골든타임·안전성·생존 개선을 검증하지 않았습니다.

사용성 측정과 구분

문의 수는 업무 부담의 간접 지표입니다. 실제 참여자의 수동·음성 입력시간과 병원 검토시간 비교는 아직 완료되지 않았습니다.

화면 확인 순서

  • 정상·변경·무응답 기록을 각각 열기
  • 조건 변경 #66과 #72에서 목적지가 다른지 확인
  • 연구 사례의 비교 방향과 같은 환자 ID 확인
  • 미도착의 빗금 막대와 성공 상태 확인
  • 새 검증의 902명 도착·85명 미도착을 함께 설명
자료 출처와 보존 범위
