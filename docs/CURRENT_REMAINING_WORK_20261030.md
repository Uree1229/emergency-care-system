# 현재 남은 작업 — 최종발표 제외

2026-10-30 기준본 후속. **알고리즘 추가 개선·새 후보 실험은 종료했고, 최종발표 제작은 보류한다.** 공통 실행본 v1로 현재 PC의 실제 화면 흐름·복구를 확인하고 병원 담당자 재시도 범위를 v1.1로 보완했다. 4번은 **PC 범위 부분 완료**이며, 사용자는 현재 이 PC만 사용할 수 있다고 답했다. 휴대폰·독립 브라우저·실제 네트워크 장애·마이크·다른 물리 PC는 남아 있다. [PC 검증 결과와 한계](DEVICE_FLOW_PC_VALIDATION_20261030.md)를 따른다.

1·2번 완료 범위와 증거는 [메인 음성·이송과 검토·추천·알림 연결](MAIN_UI_INTEGRATION_20261030.md)에 있다. 관련 101개 회귀, 합성 환자 신규 등록부터 같은 ID의 도착 확인, 기존 환자 명시 적용과 양쪽 알림 기록을 확인했다. 실제 마이크·휴대폰·사람 대상 측정 완료를 뜻하지 않는다.

이전 [전체 잔여 목록](PROJECT_REMAINING_WORK_20261030.md)에는 이후 완료된 항목이 남아 있다. 현재 우선순위는 이 문서를 따른다. 저장 기록을 보여주는 [시연 안내](DEMO_RUNBOOK_20261030.md) 완성과, 사용자가 직접 새 환자를 입력해 끝까지 수행하는 통합 리허설은 구분한다.

## 측정에서 구분할 점

이전 사용자 마이크 1회 기록은 있다. 따라서 ‘마이크로 한 번도 시험하지 않았다’고 정리하지 않는다. 다만 당시 인식문을 수정 후 다시 넣어 통과한 결과는 **새 녹음으로 인식 정확도가 개선됐다는 증거가 아니다.** 최신 수정 뒤 PC·안드로이드 등에서 다시 확인해야 한다.

수동/음성 짝비교 보고서는 현재 실제 참여자·과업 **0, 미측정**이다. 합성 문자열·가짜 인식기·TTS/잡음 조합·자동 조작 24초는 사람의 사용성 성과와 구분한다. 문의 수 감소를 병원 검토시간 감소로 바꾸지 않는다. 학생이 참여하면 학생 대상 결과라고 남긴다.

측정 준비는 [사용성 평가 절차](USABILITY_EVALUATION_20261030.md)와 [빈 측정 양식](../outputs/usability_evaluation_20261030/preparation_v1/measurement_template.csv)을 사용한다. 새 합성 환자로 진행하며 성공·실패·중단과 사용한 버전을 함께 보존한다.

## 이번 필수 범위에 넣지 않는 확장

- **최종발표 슬라이드·발표 대본 확정·발표 영상 편집:** 사용자 요청으로 보류한다.
- **추가 알고리즘·수용 예측 모델·치료 자원 모델 확대:** 현재 범위를 유지한다. ICU/NICU/분만/수술실을 새로 최적화하는 작업을 이번 잔여 필수로 추가하지 않는다.
- **외부 공개 운영:** 실제 외부 서비스로 제공하기로 할 때 로그인·병원별 권한·HTTPS·배포와 자료 보관 기준을 별도 진행한다. 로컬 합성 시연의 필수 완료와 구분한다.
- **실제 병원 통신·현장 도입·의료진 절차 검토:** 협력 기관이 필요한 별도 범위다. 공개 API 조회나 학생 역할 시험으로 완료 처리하지 않는다.
- **블루투스 PTT 버튼·기기 내 인식·백그라운드 푸시:** 실제 사용할 기능으로 정했을 때 추가 검증한다. 현재 웹 흐름 완성의 선행 필수는 아니다.
