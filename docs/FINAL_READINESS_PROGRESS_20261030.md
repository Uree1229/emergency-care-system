## 이번 결과로 말할 수 있는 내용

최신 서버 기능 9종과 카카오 도로 통합 4종이 전용 합성 DB에서 검증됐다. 지도에서는 대체 수용이 도착해도 담당자가 명시적으로 변경하기 전까지 기존 목적지가 유지되는 것을 확인할 수 있다. 기존 서버·시연 DB는 변경하지 않았다.

새 배정 연구에서 H1−R1의 도착 제한값은 27명 감소·34명 증가·542명 동일이었다. 동일 542명에는 양쪽 미도착 40명이 포함된다. 개인 최대 악화 67분, 우선군 4의 최대 악화 51분을 함께 보존했다. R0 대비 도착·치료 시작 기록 상실 1명도 확인했다. [최종 정책 결정](FINAL_ALGORITHM_DECISION_20261030.md)은 운영의 고정3 문의·CP-SAT 유지와 별도 H1 미채택이다. 원 사건에 대한 기존 산술 감사 12,529항목과 후속 사후 검토 14,049항목은 별도 범위로 보존한다.

후속 [대기 보호 W1](WAITING_PROTECTION_20261030.md) 구현·검증도 완료했다. 기존 36환경에서는 한 67분 지연을 줄였지만 다른 환자는 H1보다 최대 83분 늦어졌고, 새 60환경 987명에서는 H1 대비 개선 0명으로 사전 보호조건 FAIL이었다. 새 자료의 H1/W1−R1 최대는 124분(우선군4 112분)이며 원 자료의 67분과 구분한다. 테스트 37개·96환경 기술감사/원본 재검사 PASS와 채택 조건 FAIL은 별개다. W1도 미채택, 운영 설정 유지이며 이번 96환경은 차기 후보의 미사용 검증으로 재사용하지 않는다.

실제 사용자 측정이 없으므로 음성으로 업무가 빨라졌다거나 병원의 부담이 줄었다는 결론은 아직 없다. 빈 양식과 결과는 **미측정**으로 저장한다.

관련 Python 회귀 42개와 지도 계산 6개, 뷰어 JavaScript 구문 검사, 기존 동결 21파일 일치 검사를 통과했다. 최초 배치에서 기존 테스트 7개의 OS 임시폴더 접근이 막혀 작업 폴더 안 TEMP로 다시 실행해 통과했다. 저장 raw 36개는 원본 영수증을 보존한 새 복사본에서도 재감사를 통과했다. 최종 증거는 `.codex-build/final-readiness-20261030/completion-check.json`에 있다.

실제 브라우저에서 정상 도착, #66의 기존 H1 유지, 명시적 변경 후 H2 도착, 무응답 종료·미배정을 확인했다. 이동이 없는 사례는 ‘이동 기록 없음’, 무응답 마감 뒤에는 ‘자동 문의 종료·미배정’으로 표시한다. [지도 화면 캡처](../.codex-build/final-readiness-20261030/road-replay.jpg)와 같은 폴더의 `browser-*-ax.txt`에 확인 상태를 보존했다.
