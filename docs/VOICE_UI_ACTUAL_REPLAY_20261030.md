## 원래 순서의 재생

긴 설명과12개 답변을 원래 질문ID에 맞춰 같은 새 세션에서 순서대로 전송했다. 초기 설명을 포함한13단계 중11단계가 HTTP200, 이미 해결된 질문2건은 정상적인409였다.

- 과거의 `혈압 110에 70` 답변: 새 코드가 초기 설명의120/80을 이미 읽어 혈압 질문이 해결됐으므로 `VOICE_QUESTION_CHANGED`를 반환했다.
- 과거의 마지막 호흡수 답변 `20`: 앞선 `분당 20분`에서 호흡수20이 반영되어 같은409를 반환했다.
- 409는 초안 버전을 변경하지 않고 현재 값을 보존했다. 질문별 독립 재생에서는 두 원문 모두 정상 반영을 확인했다.
- 이 검사는 과거 질문을 강제로 다시 보내는 방식이다. 현재 UI에서 같은 질문 횟수나 실제 업무시간이 줄었다는 측정은 아니다. 이후 새 측정값 보고는 기존 관찰·수정 흐름으로 다뤄야 한다.
