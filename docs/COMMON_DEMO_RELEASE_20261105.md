실행은 PowerShell에서 배포 폴더로 이동해 `./START.ps1`을 사용한다. 각 실행은 새 회차의 합성 DB를 만들며 실제로 기동된 주소는 `runs/<회차>/ready.json`에 기록한다. 종료는 `Ctrl+C` 또는 `./START.ps1 -Action stop -Run <회차>`다.

확인한 주 흐름은 입력 초안 확인·등록 → 고정3 문의 → 병원 질문·답변·수용 → CP-SAT 추천 → 구급대원 확정·출발·대화 → 자원 경합 재확인 → 병원 조정 요청 → H02 수용 → 구급대원 목적지 변경 → H02 도착이다. 수치 후보 90/19 충돌의 확정·전송 차단도 확인한다. 입력은 준비한 합성 인식문이며 역할 판단은 검증기가 API로 수행한다.

실제 구급대원 화면의 등록 수요는 `ed_bed:1`이다. 주 시연도 H01/H02의 진료 자리를 각각 1로 준비하고 H01 외부 유입이 그 자원을 점유하는 조건을 사용한다. 기존 전문팀 OPS 사례는 API 백업 분기로 둔다. 병원 연동 오류 복구 결합본은 별도 부록으로 보존한다.
