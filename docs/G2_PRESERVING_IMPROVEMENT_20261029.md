# G2 성과 보존 조건을 적용한 G5 개선 실험

G2의 미배정·고우선순위 성과를 유지하면서 지연을 줄이는 후보를 구현하고, 기존 자료 회귀와 별도의 새 자료 검증을 진행했다. 실험 비교 기준은 기존 G2로 유지하며, 서버와 시뮬레이터의 운영 설정은 변경하지 않았다.

새 1,845개 합성 환경·13,670명의 검증에서 보호조건은 통과했다. G2의 선정·도착 성공 ID 상실은 0/0명, 가중치4 3,524명 중 도착시간 악화는 0명이다.

시간 개선은 1명, 지연 증가는 0명이며, 전체 도착 경과시간 차이 합계는 -3분이다. 세 main 계층에서 보정 구간이 모두 0을 포함해 통계적으로 뚜렷한 시간 우위는 확인하지 못했다. G5는 연구 후보로 보존하고 기본 정책 교체 근거로 사용하지 않는다.

G5는 현재 G2가 선택한 환자 ID, 실험 우선순위 가중치 4 환자의 목적지, 병원별 자원 사용량을 고정하고, 선택 환자의 이동시간을 늘리지 않는 후처리 후보다. 인력·병상을 늘리거나 임상적 예후 개선을 검증한 시스템은 아니다.

|---|---:|---:|---|---|---|
| regression | 1,845 | 13,605 | 기존 해시 결합 결과 | 새 실행 | known 회귀·기술 확인 |

## 계산시간은 환자 시간과 분리

| phase | G2 결정 계산 총시간(초) | G5 결정 계산 총시간(초) | 해석 |
|---|---:|---:|---|
| regression | 2.091013 | 1.394876 | cached timing: 공정한 대응 속도 비교 아님 |
| validation | 2.0354 | 1.389082 | 새 실행 기술통계; 실행 순서·장비 영향 있음 |

이산 사건 시계에 계산 wall time을 더하지 않는다. G2가 H1을 채택할 수 없는 singleton·전원 배정 배치에서 탐색을 생략한 시간 절약을 환자 도착시간 절약으로 표현하지 않는다.

## 기존 85분 추가 지연 사례

이 사례의 P08 대신 가중치4 P12를 우선 배정한 G2 선택을 유지했다. P08의 최종 도착 시각은 G2·G5 모두 시뮬레이션 t=100, P12는 모두 t=14다. G5가 기존의 85분 추가 지연을 해결했다고 주장하지 않는다.

## 알고리즘·감사 범위와 한계

- 현재 수용 응답과 현재 자원으로 G2 기준 계획을 얻는다. selected ID 집합, 가중치4 목적지, footprint와 개별 이동시간 상한을 보존하고 엄격 단축이 있을 때만 변경한다.
- 가중치 1·2·4는 실험 설정이다. 임상 중증도·의료진 우선순위 합의를 검증한 결과가 아니다.
- fresh는 기존에 실행하지 않은 seed를 같은 합성 생성모형에 넣은 검증이다. 새로운 현장 데이터나 다른 생성모형에 대한 일반화 검증은 아니다. stress에는 같은 구조의 반복이 포함된다.
- 같은 현재 자원 사용량이어도 도착·처치 환자와 미래 자원 해제 순서가 달라질 수 있다. 현재 제약 보존은 모든 미래 상황에서의 전체 성과 보증이 아니다.
- 감사는 저장된 현재 입력, 수용 응답·계획 제약, 실제 commit와 환자 endpoint 산술을 검증한다. 모든 과거·미래 자원 점유 이력을 독립적으로 다시 재생·재구성한 감사라고 주장하지 않는다.
- 전체 모듈 테스트 80개 통과(새 G5 23개). 독립 완전열거, 예산·불변조건, 대형 입력·원본 85분 사례 회귀·감사 위변조 거절을 포함한다. 테스트 통과만으로 현장 효과나 채택이 입증되지는 않는다.
- 운영 기본값은 이 전달 작업으로 변경하지 않는다. 기존·fresh의 작은 효과나 불리한 결과도 보고서·CSV에 그대로 보존한다.

## 후속 개선

엄격 Pareto 목적지 변경의 기회가 희소하면 큰 지연 개선은 기대하기 어렵다. 다음 후보는 G2 배정과 분리해, 종료된 문의의 빈 슬롯 보충·재문의 대기 정책을 연구하는 방향이다. 문의 정책 변경도 수용 응답과 자원 점유를 바꾸므로 같은 보호조건의 새 전체 재생이 필요하다. 실제 응답률 증가나 임상 효과는 아직 주장하지 않는다.

## 전달 파일

- `outputs/g2_preserving_improvement_20261029/regression`, `validation`: summary/protocol/entries/source-freeze/index, 결과 CSV 2종, 원본 report의 gzip.
- `sources`, `tests`: 새 소스 3개와 테스트 2개 사본. 나머지 의존 소스 해시는 phase별 source-freeze에 보존했다.
- `analysis`: known 기회 감사·문의 후속 연구·설계 검토·독립 평가 검토. 독립 검토의 정확한 범위는 첨부 원문을 따른다.
- `evidence`: 최종 테스트 증거 및 존재하는 결정문/검증 허가 파일. 결정문이 없으면 전달 스크립트가 채택 판정을 만들어내지 않는다.
- `artifact-manifest.json`, `artifact-manifest.sha256`: 전달 파일과 이 문서의 크기·SHA-256. manifest 자체는 자기목록에서 제외하고 별도 checksum으로 검증한다.
- 사례 raw gzip 전체는 복제하지 않는다. index가 원 작업공간의 raw 경로와 해시를 가리킨다. 원시 사건 재감사에는 해당 raw와 freeze에 결합된 의존 소스가 필요하다.
