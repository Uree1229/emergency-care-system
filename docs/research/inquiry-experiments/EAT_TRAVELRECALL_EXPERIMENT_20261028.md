# 빈 공개 대기열을 이용한 조기 문의 복원

2026-10-28. 성공 37건과 case240 P02의 118초 도착 지연 해소를 유지하면서 Travelwake에서 포기한 선정 대기 19초를 복원하는 실험이다. 첫 후보 Travelrecall은 같은 12환경·42명에서 **14초를 복원**했다. 19초 복원 목표는 아직 실패이며 5초가 남는다. 기존 소스·원문·문서는 변경하지 않는다.

## 규칙과 사전 목표

기존 Travelwake의 거리 보호와 미확인 이동시간 차단을 유지한다. 조기 판단에서만, 이동시간이 확인된 더 먼 후보라도 현재 공개된 타환자 미해결 문의가 그 병원에 0건이면 원 H가 제안한 조기 송신을 허용한다. 180초를 넘은 미해결 문의도 타환자 문의 수에 포함한다. 식별자·시각이 불명확한 대기열 행은 대기열이 비었다는 근거로 사용하지 않는다. 정기 판단·첫 공동 문의·H 수학·4/10 문의 한도·기존 다음 검토 상한은 유지한다.

이 규칙은 관측한 개발 자료의 공개 대기열 차이를 본 뒤 설계했다. 대기열 0은 현재 캡처에서의 값이며 실제 도착이나 미래 경쟁의 비퇴행 보장이 아니다. 기존 H 제안과 원래 거리 필터 결과, 큐 예외 전후 송신을 분리해 남기고 필터 후 H 기대비용을 다시 계산하지 않는다.

검증 전에 기존 37명의 성공 식별자 보존, P02 선정 성공·도착 비용 767초 이하, 전체 선정 대기 4,971초 이하를 주 목표로 고정했다. 이는 Travelwake 4,990초에서 19초 이상 감소하는 조건이다. 세 환자 case7 P03≤160초, case240 P02≤127초, case265 P01≤236초의 직접 복원은 별도의 선택 조건으로 보고한다. 다른 환자의 단축으로 총 19초를 충족하는 것과 세 환자 모두에게 직접 복원하는 것을 혼동하지 않는다.

원래 27개 조건과 연구용 14개 조건은 그대로 유지한다. TW·Travelwake·Declinewake의 완전한 실제 참조 벡터를 각각 비교하며 환자마다 더 좋은 값을 골라 만든 가상 기준은 사용하지 않는다.
