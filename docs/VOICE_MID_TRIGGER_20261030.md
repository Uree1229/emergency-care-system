# 대화 중간 명령과 저장 후 이어가기

대상: `/paramedic/quick-test.html` 대화형 음성 기록 화면. 브라우저가 확정한 텍스트에 적용한다. 실제 STT 정확도를 개선하거나 소음 제거를 수행하는 기능은 아니다.

## 동작

| 확정 인식 예시 | 저장 본문 | 이후 동작 |
|---|---|---|
| 47세 남성. 중단 맥박 92. | 47세 남성. | 저장 확인 후 녹음 종료. 맥박 문장은 미반영 검토용 |
| 혈압 120에 80. 녹음 종료 | 혈압 120에 80. | 저장 확인 후 종료, 다음 말하기는 같은 초안에 추가 |
| 47세 남성. 병원 추천해줘 혈압 120에 80. | 47세 남성. | 저장 확인 후 추천 준비. 혈압 문장은 미반영 검토용 |
| 처치 종료. 종료하지 마. 보호자가 “그만”이라고 말함 | 전체 본문 | 중단 명령으로 실행하지 않음 |

첫 유효 명령만 실행한다. 명령 뒤에 다른 명령이 있어도 자동 실행하지 않는다. 확정 인식 조각을 합쳐 탐지하므로 `병원` / `추천해줘`처럼 나뉜 인식도 처리한다. 임시 인식은 실행하지 않는다. 토글과 누르는 동안 말하기 모두 적용한다.

녹음 종료 중 늦게 온 확정 인식까지 합쳐 저장 직전에 다시 검사한다. `종료` / `하지 마`, `병원 추천해줘` / `라고 환자가 말함`처럼 부정·간접보고로 바뀌면 명령과 자동 저장을 실행하지 않고 전체 원문을 미반영 검토칸에 남긴다. `종료` / `해 주세요`처럼 명령의 공손한 어미가 이어진 경우는 같은 명령으로 처리한다.

명령 앞 본문은 녹음 시작 시 선택한 auto/dictation/command 또는 해당 확인 질문 답변으로 저장한다. 저장 API가 성공해야 후속 동작을 연다. HTTP 200이면서 답변을 해석하지 못한 경우도 원문 저장 성공으로 구분하며, 해석 실패 항목은 계속 검토 대상으로 남긴다. 명령만 있으면 새 빈 초안을 만들지 않는다. 기존 초안이 있을 때의 추천 단독 명령은 그 초안으로 준비하고, 없으면 환자 정보를 먼저 요청한다.

## 저장과 오류 처리

- 응답 유실: 기존 `QuickSession`의 요청 본문·utterance ID·버전을 유지해 재시도한다. 결과 확인 전에는 후속 동작을 실행하지 않는다.
- 409 충돌: 최신 초안을 읽고 검토를 안내한다. 오래된 명령을 자동 재실행하지 않는다.
- 기존 추천 준비가 있더라도 새 저장이 실패하면 그 계속 버튼을 무효화한다. 확정 실패한 본문은 명령 뒤 문장과 함께 미반영으로 보존하며, 불확실 요청의 재시도가 확정 실패한 경우도 같은 경로를 쓴다.
- 마이크 종료 중 늦은 확정 인식 및 명령 뒤 본문: API에 자동 반영하지 않고 미반영 목록에 보존한다. 이후 녹음에도 유지한다.
- 직접 입력 검토 후 반영 성공: 해당 미반영 목록을 해소한다. 실패하면 유지한다.
- 입력 본문 4000자 초과: 원문을 남기고 전송하지 않는다.

## 추천 준비와 같은 초안 복원

추천 명령은 저장 성공 뒤 준비 패널을 연다. 사용자가 계속 버튼을 누르면 같은 탭의 전용 `sessionStorage` 키 `paramedic.voice.handoff.v1`에 서버 원점·actor ID·session ID·최소 버전·추천 의도·미반영 텍스트만 담는다. 유효기간은 10분이다. 원점과 스키마를 검증하며 미반영 텍스트가 4000자를 넘거나 저장이 불가능하면 이동하지 않고 원래 화면을 유지한다. URL에는 초안 ID나 환자 텍스트를 넣지 않는다.

메인 화면은 전달받은 actor로 같은 초안을 GET 복원하고 ID·버전을 확인한 뒤 기존 복원 키를 갱신한다. 실패하면 새 빈 초안을 자동 생성하지 않는다. 전달된 미반영 텍스트는 직접 입력 검토칸에 놓으며 자동 반영하지 않는다. 정보 확인 → 화면의 초안 확인 → 위치·동의 → 명시적인 환자 등록 → 후보 조회 순서를 따른다. 기존 등록 환자 정보와 달라진 초안을 자동 혼합하지 않는다.

## 검증 범위

`test_paramedic_recording_control.mjs`는 사람이 먼저 작성한 명령/비명령 예시와 원문 범위를 검증한다. `test_paramedic_quick_page.mjs`는 실제 페이지 코드와 VoiceClient·QuickSession을 실행하되 DOM·캡처·서버는 모의 처리한다. `test_paramedic_draft_handoff.mjs`와 메인 페이지 시험은 만료·원점·저장 오류·같은 초안 복원·실패 시 빈 초안 방지를 확인한다.

별도 HTTP 통합 검증은 실제 서버와 새 합성 SQLite DB를 사용한다. 실제 사용자 녹음 DB·마이크·클라우드 STT·실제 병원 전송은 사용하지 않는다. 음성 인식이 다른 단어를 반환하거나 인용 경계를 생략하면 의도와 달라질 수 있으므로 화면의 원문과 저장 결과를 확인한다.
