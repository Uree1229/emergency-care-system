# 배정 알고리즘 개선: 지연 원인과 G3·G4 비교

2026년 10월 29일. 기존 R0/R1/H1/G2와 동결 실험 자료를 보존하고 별도의 연구 후보 G3를 추가했다. 팀원 프론트엔드·실제 병원·기존 업무 DB는 변경하지 않는다.

## 1 일반 환경의 최종 미배정 수가 같았던 이유

기존 확대 평가의 주 평가 1,800환경·13,426명에서 R1/H1/G2의 미배정49명은 환자 ID도 같았다.

- 47명은 처음부터 진료조건과 자원 총량을 충족하는 병원이 없었다. 필요한 진료분야가 없는13명과, 분야는 있으나 요구 자원 총량이 부족한34명이다.
- 나머지2명도 관측 종료까지 유효 수용 응답을 얻지 못해 현재 배정 규칙의 선택지에 들어오지 못했다. 다른 배정으로 전체 회신 경로가 달라질 가능성까지 없다는 뜻은 아니다.
- 단일 발생의 공동 판단은 전부1인 배치다. 순차 발생도3,191배치 중3,094개(약97%)가1인이라 공동 최적화 기회가 작다.
- 다수 발생에서는 G2가265배치에 개입했다. 현재 배치의 수용 인원 증가166회와 동수의 가중치4 우선 교환99회다. 그러나 관측180분, 치료 점유15~60분, 초기 점유90분 이내 해제로 거리순의 대기 환자도 결국 대부분 배정됐다.

따라서 최종 미배정 하나만으로는 빠른 배정과 지연 꼬리의 재분배를 구분하기 어렵다. 사후 진단에서5분 내 선정·30분 내 도착 개선과90분 내 도착 감소가 같이 관찰됐다. 이 구간은 원래 주 지표가 아니라 원인을 설명하기 위한 사후 분석이다.

## 2 85분 지연의 정확한 경로

대상은 합성 사례 `main_surge_0096 / P08`이다.

| 시각 | 거리순 R1 | 기존 G2 |
|---|---|---|
| 8분 | P08을 H04에 확정 | 같은 자리에서 P08 대신 실험 가중치4 P12를 선택 |
| 9분 | P08 이송 중 | P08의 이전 수용 응답 재확인 실패 |
| 15분 | P08 도착 | 병상·전문팀 경합으로 탐색 지속 |
| 78분 | - | P08 H01 확정 |
| 100분 | - | P08 도착 |

추가85분은 **선정 대기70분 + 이동 증가15분**이다. 단순히85분 더 먼 병원을 고른 것이 아니다. G2의 현재 목적함수는 같은 인원에서도 실험 가중치4 환자를 더 받으면 교환을 허용한다. 그 결과 P12는 R1에서131분, G2에서14분에 도착해117분 빨라졌다.

이는 자원 검증 오류가 아니라 명시적인 우선순위 재분배와 장기 지연 보호 부재의 결과다. 이후 H04 병상과 전문팀의 결합 점유·다른 환자의 확정·재문의 순서가 P08의 대기를 키웠다. 원인 추적에 사용한 미래 자원 해제·미래 회신 시각은 알고리즘의 입력으로 사용하지 않는다.

## 3 새 G3의 선택 규칙

G3는 G2의 실험 가중치 교환 목적을 바꾼 **별도 정책 후보**다. 실제 임상 중증도 기준이나 전 과정 최적해를 제시하지 않는다.

1. 지금 받은 유효 수용 응답·현재 자원·이동시간으로 caller 순서의 거리순 기준안 B를 만든다.
2. B에서 배정 가능한 환자 ID를 현재 후보 계획에서도 모두 유지한다. 이송 중의 기존 확정자를 새로 취소하는 규칙이 아니다.
3. 추가 환자를 배정하려면 다중 자원과 병원 간 연쇄 이동을 탐색한다. 기준안의 환자를 미배정으로 바꾸는 후보는 거부한다.
4. 같은 배정 인원의 교환은 기존 환자 누구의 현재 예상 이동시간도 늘리지 않고 일부를 줄일 때만 허용한다.
5. 추가 배정에 필요한 우회는 최대 양의 추가 이동과 추가 이동 합을 목적에 반영해 최소화한다. 임상적으로 검증되지 않은5분·10분 상한을 안전 기준처럼 만들지 않는다.

정확한 사전순 목적은 **미배정 실험 가중치 → 미배정 수 → 기존 기준안 환자의 최대 양의 추가 이동 → 추가 이동 합 → 가중 이동시간 → 변경 목적지 수**다. 가중치를 먼저 고려하므로 총인원 최대화 보장이라고 설명하지 않는다.

탐색은 부분 노드와 최종 후보를 포함한2,048작업 예산으로 제한한다. 작은 정책 영역은 그 예산 안에서 완전 탐색하고, 큰 영역은 기준안에서 시작하는 제한 증가경로 탐색을 사용한다. 기술적10초 안전상한 소진은 유효한 성능 결과가 아니라 명시적 실패다.

## 4 보장하는 범위와 보장하지 않는 범위

보장 범위는 **해당 G3 분기의 현재 입력 안에서** 기준안 배정 ID 보존, 수용 응답·자원 제약 준수, 동수일 때 개인 예상 이동시간 비악화다.

이 현재 기준안은 R1 분기의 전체 반사실 경로가 아니다. 오늘의 선택이 이후 자원·회신·다른 환자에게 영향을 주므로 실제 최종 도착시간·모든 환자 비악화·전역 최적성·가중치4 집단 비악화는 보장하지 않는다.

원85분 사례에서 G3는 P08을15분 도착으로 복구했으나, P12는 G2의14분에서132분으로 늦어졌다(R1은131분). 한 사람의 지연을 없앤 것만으로 전체 개선을 주장하지 않는다.

## 6 첫 G3의 전체 회귀와 미채택

알려진1,845환경에서 G3는 일반 환경의 미배정·미도착을 유지했고, 다수 발생의 R1 대비 양의 개인 지연을0.8281→0.4888분, 최대 추가 지연을85→71분으로 줄였다. 그러나 대규모 동시발생74명의 미배정은 G2의1명에서15명으로 늘었다. 실험 가중치4 환자의 다수 발생 도착 제한시간 합도 G2보다2,666분 늘었다. 따라서 G3를 채택하거나 새 검증의 성공 후보로 삼지 않았다.

대형5건 모두에서 기준안 환자 전원을 보존하면서 G2와 같은 배정 수를 달성하는 실행 가능 해를 별도로 구성했다. 보호 제약 때문에 불가능한 것이 아니었다. G3는 첫 미배정 환자 한 명을 추가한 뒤 그 환자의 동수 재배치 대안만 계속 열거해 예산을 소진했다. 새 배정안을 기준으로 다음 미배정 환자를 추가하는 단계에 도달하지 못한 검색 스케줄 결함이었다. 첫 사례는 예산을64→32,768로 늘려도13명에 머물렀다.

실패한 G3의 코드·회귀 원문·잠금·미채택 판단은 `.codex-build/protected-evaluation-20261029/regression/`에 보존했다. 뒤의 G4 결과로 덮어쓰지 않는다.

## 7 G4: 같은 보호 정책에서 증원 탐색을 먼저 완료

G4의 실행 가능 조건·보호 제약·목적함수는 G3와 같다. 바꾼 부분은 검색 순서다.

1. 추가 수용을 찾는 단계와, 같은 수용 수준에서 이동 손해를 정제하는 단계를 분리한다.
2. 미배정 가중치·인원 개선을 찾으면 현재 루트의 대안 열거를 즉시 끝내고 새 배정안을 incumbent로 삼아 탐색을 다시 시작한다.
3. 현재 자원만으로 계산한 완화 하한을 사용해 더 많은 수용이 불가능한 탐색을 줄인다. 미래 점유 해제·미래 환자·미래 회신은 사용하지 않는다.
4. 부분 노드를 포함한 전체2,048작업 예산은 유지한다. 예산을 더 주어 이득을 만든 비교가 아니다.

대형5건의 목표 배정 수15·14·15·14·15명을 현재 보호 조건을 유지하며 모두 회복했다. 원85분 사례 P08도15분 도착을 유지했다. 이는 알려진 사례의 회귀 복구이며 새 검증 효과와 구분한다. P12의 우선 배정 이익 손실도 그대로 별도 평가한다.
