# 현재 시연 안내

2026-10-30. 사용자 결정에 따라 **추가 알고리즘 개선·후보 실험은 여기서 종료한다.** 운영 기준은 고정3 문의 + CP-SAT `severity_first`, 계산 예산 3초를 유지한다. 최종발표는 아직 한 달 이상 남았으므로 슬라이드 제작과 발표 시간 확정은 보류한다. 이 문서는 현재 구현과 저장된 결과를 팀에서 확인하기 위한 시연 안내다.

## 시작 화면

시연 안내 페이지: **[http://127.0.0.1:18045/demo.html](http://127.0.0.1:18045/demo.html)**.

정상·조건 변경·실패 지도 링크와 연구 사례 5개, 새 검증 요약, 한계를 한곳에 모았다. 연구 카드는 이미 저장된 사건의 발췌이며 새 알고리즘 실행이나 실시간 병원 통신이 아니다. 기능 지도에서 쓰는 병원 ID `H1`과 연구 방식 이름 `H1`은 서로 다른 표기다.

기존 18045 뷰어가 켜져 있으면 페이지를 바로 연다. 꺼져 있으면 PowerShell에서 다음 명령으로 시작한다.

```powershell
Set-Location -LiteralPath 'C:\Users\PC\Documents\ChatGPT\캡스톤 디자인'
$demoPython = 'C:\Users\PC\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe'
& $demoPython -m simulation.viewer_server --port 18045 --reuse-data --no-browser
```

이 PC의 기본 Python 3.14와 프로젝트 솔버 환경이 다르므로 위 3.12 경로를 사용한다. 다른 PC에서는 설치한 Python 경로로 바꾼다. `--reuse-data`는 저장된 자료만 제공하며 새 실험을 생성하지 않는다. 기존 서버·DB를 초기화하지 않는다. 종료는 해당 터미널에서 Ctrl+C다.

18045가 다른 용도로 사용 중이면 `--port 18047` 등 빈 포트를 지정하고 `http://127.0.0.1:18047/demo.html`을 연다. 안내 페이지의 지도 링크는 현재 포트를 따른다. 기존 프로세스를 임의로 종료하지 않는다.

## 반드시 함께 말할 한계

- 환자·자원·응답은 합성이다. 실제 병원 수용·현장 성능과 임상 결과를 검증한 자료가 아니다.
- 새 검증도 조건당 5환경이다. 환자 987명을 독립 표본으로 취급하거나 현장 전체의 평균 효과로 확대하지 않는다.
- 30/60/120분 기준은 실험 지표이며 검증된 임상 골든타임이 아니다.
- 현재 원장·수용·배정·사건을 감사한 범위다. 전체 자원 이력의 독립 재생과 모든 미래 환자의 비악화를 보장하지 않는다.
- 문의 수는 병원 업무의 대리 지표다. 수동/음성 완료시간·오류·수정·터치·실제 병원 검토시간은 아직 사람에게 측정하지 않았다.
- 저장 도로 재생은 실시간 교통·실제 GPS·구급차 우선주행을 보여주지 않는다.
