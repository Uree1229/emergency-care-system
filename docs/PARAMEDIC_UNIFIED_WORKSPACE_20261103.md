# 대화형 이송노트 통합

구급대원 기본 주소 `/paramedic/`에서 대화형 기록, 상세 검토, 환자 등록, 병원 연결을 순서대로 진행한다. 이전 `quick-test.html` 주소도 동일한 작업공간으로 연결된다. 단계 이동 때문에 다른 앱을 띄우거나 새 음성 초안·환자를 만들지 않는다.

- 음성·채팅 입력과 상세 검토는 같은 `VoiceClient`, `QuickSession`, 환자 기록을 사용한다.
- 중요한 수치·부정 표현을 확인한 뒤 상세 검토로 이동한다. 입력하지 않은 항목은 모름·미측정으로 남기며 정상·0·증상 없음으로 채우지 않는다.
- 내용 확인, 환자 등록, 위치 사용과 동의는 명시적으로 실행한다. 등록은 병원 문의를 자동 시작하지 않는다.
- 작성 중인 값과 미확인 요청은 같은 탭에서 복구한다. 불확실한 요청은 조회 후 원래 요청 ID·본문으로 명시적으로 재시도한다.
- 등록 후 새로고침·환자 기록 전환도 기존 환자로 복원한다. 등록된 초안을 다시 등록하지 않는다.
- 기존 전체 입력 화면은 `?view=full`의 복구 호환 경로로 보존한다. 일반 경로는 대화형 통합 화면이다.
- 서버가 인계 공유 기능을 제공할 때만 해당 연결을 표시한다. 기본 병원 문의·이송 진행은 기존 환자 웹으로 이어진다.

GitHub 최신 코드에 있던 명령 확인 대기·시험 기록과 인식 후보 문맥 검토를 유지하면서 통합했다. 서버 변경은 남은 항목의 미확인 처리와 해당 응답 범위에 한정하며, 기존 인식 후보 재확인·환자 확인 조건을 유지한다. 배정 알고리즘은 변경하지 않는다.

검증: 구급대 UI 자동 검사 2,379개 통과. 서버 미확인 처리·기존 인식 후보·확인 질문 관련 검사 77개 통과. 별도 로컬 서버와 가상 환자에서 직접 입력 → 복창 확인 → 상세 검토 → 등록 → 병원 후보 표시 → 새로고침 복원을 실제 브라우저로 확인했다. 이 결과는 실제 마이크 정확도, 현장 소음, 임상 효과나 실제 병원 수용 검증을 의미하지 않는다.
