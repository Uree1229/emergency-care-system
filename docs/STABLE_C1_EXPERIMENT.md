# C1 동률 배정의 선택 순서 안정화

2026-10-15 · 합성 시뮬레이션의 C1 개선 · 운영 서버 미적용

## 결과

같은 목적값의 C1 해가 우선 배정 환자를 바꾸면서 P01이 기존 보호보다 최대 37분 늦어진 문제를 대상으로, **동률일 때 검증된 우선순위·요청 시각·환자 ID 기준 배정안을 유지**하도록 개선했다.

개발 78사례 × 17분기 후 소스·설정·런타임을 잠그고, 미사용 시드의 **검증 156사례 × 17분기 = 2,652회**를 실행했다. 각 분기의 환자 실행 수는 450개다. 병원·환자·자원·회신·이동·처치시간은 모두 합성이다.

문제가 있었던 `no_alternative_hospital`의 새 검증 6사례 결과:

| 항목 | 동결 C1 | 안정화 C1 |
|---|---:|---:|
| P01 도착 시각 | 33~41분 | **4분** |
| 기존 보호 대비 P01 추가 지연 | +29~37분 | **0분** |
| P02 도착 시각 | 4분 | 4분 |
| P03 도착 시각 | 4분 | **33~41분** |
| 기존 보호 대비 P03 도착 변화 | 빨리 배정됨 | 6사례 모두 −1분 |
| 유형 전체 도착시간 합·최대 도착시간 | 기준 | 동일 |

**P01의 동률 선택으로 인한 추가 지연은 없어졌지만, 실제 병상 부족의 대기는 P03에 남는다.** 전체 환자의 대기 시간을 없앤 결과로 해석하지 않는다. 기존 보호는 P01/P02를 먼저 배정하고 P03이 기다리는 순서였으며, 안정화는 그 순서를 유지한다.

앞서 보고한 최대 37분은 이전 검증 시드 기준이다. 위 표는 같은 새 시드의 동결 C1과 안정화 C1을 비교한 결과이며, 새 시드에서도 +29~37분 문제를 재현하고 확인했다.

## 변경한 선택 규칙

C1은 기존의 두 목적을 그대로 사용한다.

1. 미배정 환자의 우선순위 가중치 합 최소화.
2. 첫 목적이 같으면 우선순위 가중 이동시간 합 최소화.

현재 유효 수용 응답과 보고된 가용 자원으로 안전한 기준안을 구성한다. 환자는 높은 우선순위 → 빠른 요청 시각 → 환자 ID 순으로 검토하고, 현재 수요를 충족하는 병원 중 가까운 병원 → 병원 ID 순으로 고른다.

- 기준안의 **두 목적값 모두** C1 결과와 정확히 같으면 기준안을 선택한다.
- C1 결과의 목적값이 기준안보다 엄격히 좋으면 C1 결과를 유지한다.
- 선택 후 자원 제약과 유효 후보를 다시 검증하고, 원래 솔버 제안·기준안·최종안·선택 이유를 기록한다.
- 추가 솔버 단계·작은 가중치·epsilon을 넣지 않는다. 기존 50ms 모델·탐색 예산을 유지하고 후처리 시간을 전체 호출시간에 포함한다.

두 목적값이 같은 실행 가능한 계획으로만 바꾸므로 기존 현재 모델의 증명은 유지된다. 다만 기준안이 더 나쁜 경우 다른 모든 동률 해 사이의 전역 정규화를 보장하지 않으며, 동률 기준의 전역 최적성이나 전체 이송 최적성을 주장하지 않는다.

## 선택 안정성과 전체 지연의 차이

기존 22개 정보·재확인 유형의 새 검증에서, **같은 기존 보호 C1 대비** 공통 도착 372개 결과는 다음과 같다.

| 항목 | 동결 responsive C1 | 안정화 responsive C1 |
|---|---:|---:|
| 개인별 최대 추가 지연 | +37분 | **+6분** |
| 평균 도착 변화 | −1.118분 | −1.134분 |

이 비교의 분모는 기존 22개 유형이다. 요청·ID·병원 동률 및 기준안 열세를 확인하는 새 4개 유형까지 포함하면 최대 추가 지연은 여전히 37분이다. 오래된 요청 또는 앞선 ID 환자를 먼저 보내면서 뒤 순서 환자가 병상 해제를 기다리는 의도된 선택 변경이 포함되기 때문이다.

전체 26개 유형에서 **안정화−바로 이전 responsive C1**의 공통 도착 420개는 평균 −0.029분, 24개 단축·18개 지연·378개 동일이며 최대 추가 지연은 37분이다. 이는 대부분 대기 환자의 신원을 고정한 변화다. 평균 단축이나 모든 환자의 비악화로 이 개선을 설명하지 않는다.

이번 450개 환자 결과 사전은 안정화 responsive C1과 responsive H1이 모두 같았다. 이 합성 사례 밖에서 두 알고리즘이 항상 같다는 뜻은 아니다.

## 별도 동률 사례

기존 22개 환경을 그대로 재사용하고 네 유형을 추가했다.

- **오래된 요청:** P02가 P01보다 먼저 요청했지만 ID는 뒤다. 같은 우선순위·이동비용에서 P02를 먼저 배정한다.
- **같은 요청 시각:** 환자 입력 순서를 뒤집어도 ID 기준의 같은 선택을 한다.
- **같은 거리의 병원:** 병원 입력 순서를 뒤집어도 병원 ID 기준으로 같은 현재 목적값의 선택을 한다.
- **기준안이 더 나쁜 희소 후보:** 가까운 병원을 유연한 환자에게 주는 기준안이 한 환자를 미배정시키는 경우, 더 좋은 C1 공동 배정을 그대로 유지한다.

이 네 유형도 병상 부족으로 인한 대기와 대기 환자 변경을 함께 기록한다. 기준안의 선택 기준은 재현 가능한 실험 규칙이며 임상적 우열을 추가로 판정하는 규칙이 아니다.

## 검증과 비용

**관련 테스트 485개 통과.** 독립 감사기는 원시 현재 입력에서 기준안을 별도로 구성하고, 원래 솔버 계획·기준안·최종안의 자원 가능성과 두 목적값을 검증한다. 원래 C1의 증명, 최종 배정 인원수, 후처리 시간, 정보·수용·확정·도착 기록과 비교 분모도 검사한다. 모델 증명을 동률 정규화나 실제 확정·전체 이송의 증명으로 확대하면 거절한다.

저장한 검증 파일의 별도 재감사도 통과했다.

- 세 안정화 분기의 배정 호출 **876개** 중 기준안과 동률 762개, 다른 동률 기준안으로 실제 교체 66개.
- 기준안보다 좋은 C1 해 **114개는 그대로 유지**.
- 모든 교체는 두 목적값을 정확히 보존했고, 실행 가능한 보고 자원 제약을 유지했다.
- 전체 5,059개 배정 결정, CP-SAT 모델 증명 2,543개를 원시 기록과 독립 완전탐색으로 재확인.

17분기는 이전 14개와 `stable_observed_C1`, `stable_protected_C1`, `stable_responsive_C1`이다. 기본 문의·알림·보호·병행 확인·자원 추적 조건은 각 대응 분기와 같고 동률 후처리만 바꾼다. 실행 순서를 시드·유형에 따라 순환한다.

동률 안정화 후에도 비용과 한계는 남는다.

- 미배정·미도착은 동결 responsive C1과 안정화 C1 모두 30개이며, 한쪽에서만 도착한 실행은 없다.
- 환자 수용 문의는 각각 946회, 별도 자원 수량 확인은 각각 **593회**다. 기존 보호의 자원 확인 346회보다 많은 병행 추적 비용은 이번 동률 개선으로 줄어들지 않았다.
- 보고 기반 깨우기 이벤트는 이번 벤치마크에서도 0회이며, 그 동작은 별도 단위 사례 검증 범위다.
- 최종 확정은 즉시 권위 있는 실제 자원 수량을 확인할 수 있다는 기존 합성 환경 가정을 유지한다. 운영 서버가 미보고 병원 상태를 자동 감지한다는 뜻이 아니다.
