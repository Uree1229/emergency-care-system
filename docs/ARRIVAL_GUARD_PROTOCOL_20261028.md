## 후보 규칙

현재 같은 배정 묶음의 실제 caller 순서, 이미 받은 유효 수용 후보, 현재 잔여 자원과 이동 추정으로 거리순 실행 가능 계획 B를 만든다. 같은 현재 입력에 원래 H1을 실행한 계획 H도 보존한다. **H의 배정 인원이 B보다 많고 미배정 우선순위 합도 B보다 나쁘지 않을 때만 H를 실행하고, 그 외에는 B를 실행한다.**

B는 후보 자신의 현재 세계에서 만든 한 계획이며 별도 거리순 분기의 미래를 돌려 보거나 참고한 답안이 아니다. 원 H1 제안·B·실제 G1 계획과 선택 근거를 분리해 기록한다. 현재 자원·수용 응답 제약을 모두 확인하며 최대 2,048회 탐색·10초 안전 상한을 유지한다. 문의 3곳·첫 수용 후 최대 2분 추가 대기·변경 알림과 물리 환경은 바꾸지 않는다.

이 규칙은 같은 한 명을 수용하면서 우선순위 때문에 상대를 교체하던 일부 행동도 바꾼다. 따라서 원 H1의 배치별 가중 우선순위 목적을 항상 보존한다는 주장을 하지 않는다. 우선순위 가중치 4·2·1은 실험 설정이며 실제 임상 서열 변경을 뜻하지 않는다. 전체 실행 후 우선순위별 성공과 미배정 가중 합을 별도 검사한다. 현재 계획 보호가 미래 환자 모두의 비악화를 보장하지 않는다.
