# 최종 비교 기준과 새 합성 환경 평가

최종 해석·채택 결정은 [최종 알고리즘 정책과 개선 악화 사례](FINAL_ALGORITHM_DECISION_20261030.md)에 고정했다. 운영은 `fixed_3 + CP-SAT severity_first, 3초` 유지, 별도 H1은 기본값으로 채택하지 않는다. 아래 원 평가와 보고서는 그대로 보존한다.

2026-10-30. 기존 운영·동결 연구 코드를 변경하지 않고, 별도 실행기와 사전 고정 프로토콜을 추가했다. 새 정책을 고르거나 기존 불리한 결과를 제외하지 않는다.

## 비교 층

| 층 | 비교·상태 | 목적과 예산 |
|---|---|---|
| 실제 서버 기준 | `fixed_3 + CP-SAT severity_first`, 기존 기준 보존. 이번 실험 분기가 아님 | 우선순위 4→2→1별 미배정 수를 사전식 최소화한 뒤 같은 군별 시작 지연 최소화, 3초·분 단위 치료 일정 |
| 이번 온라인 배정 연구 | 공통 고정3 문의·첫 수용 후 최대2분 추가 대기 아래 R0 회신순·R1 거리순·H1 공동 배정 | H1은 가중 미배정 합→가중 이동시간. H1 최대 2,048후보 평가·10초 기술 실패 상한, R0/R1은 순차 선택. 같은 계산량의 탐색 알고리즘 비교가 아님 |
| 별도 스냅샷 해법 비교 | 기존 H1/C1 동일 목적·10/50/200ms 연구 | 문의·이송 시간을 측정하지 않은 다른 실험. 이번 수치와 합치지 않음 |
| 문의 정책 연구 | EAT·QI/QJ 별도 결과 | 이번 문의 정책은 고정했다. 문의 연구 성과를 실제 서버 탑재 성과로 표현하지 않음 |

실제 서버도 CP-SAT을 사용하므로 ‘우리 시스템 대 CP-SAT’이라는 비교는 하지 않는다. 이번 H1과 서버는 목적함수·시간 표현·치료 자원 일정·계산 예산이 다르다.

## 사전 고정한 새 평가

프로토콜은 `config/final_evaluation_protocol_20261030.json`, 실행기는 `simulation/final_evaluation_20261030.py`다. 기존 `final_assignment_engine_20261028`와 사건·현재 입력 감사기를 그대로 사용한다.

- 12개 profile × 3개의 새로운 seed = 36환경·108분기. 새 후보 선택이나 개발 성과에 따른 표본 확대·제외 규칙이 없다.
- 병원 수 3/7/10곳, 좌표 반경 배율 0.5/1/2, 미응답 20/40/60%, 응답 지연 1~5/3~8/4~10분, 순차/동시/3물결 발생, 자원 용량 1/0.5배, 외생 자원 중단·도착 평가 후 추가조건을 조합했다.
- 실제 수용은 현재 역량·잔여 자원으로 결정된다. 임의의 수용확률을 추가해 실제 수용을 대신하지 않는다. `accept/(accept+decline)`은 관측 회신 비율로만 기록한다.
- 같은 profile의 세 분기는 동일한 초기 환자·기관·자원·잠재 회신과 독립 경로 캐시를 사용한다. 배정 후 자원·후속 회신이 달라지는 것은 결과에 포함한다. 실행 순서는 환경별 순환한다.
- profile 간에는 서로 다른 seed를 사용한다. profile 차이 전체를 특정 변수 하나의 인과 효과라고 해석하지 않는다. 각 profile 안의 R0/R1/H1 대응 비교가 분석 단위다.
- 모든 입력 SHA-256·프로토콜·의존 소스·실행 환경·실행 순서를 `execution-lock.json`에 저장한 후 첫 정책을 실행한다. 기존 출력 경로 사용을 거절하고 실행 중 소스 변경을 검사한다.
- 최종 seed는 별도 namespace의 `2**512 + SHA-512(namespace|profile|replicate)`다. 테스트는 `unit-` profile/별도 namespace를 사용해 최종 36개와 겹치지 않는다. 기존 로컬 JSON 증거를 스트리밍해 seed 교집합을 검사하고 파일 해시를 남긴다. 압축 raw·삭제된 파일·다른 PC는 스캔 범위 밖이며, ‘모든 과거 자료가 전 세계적으로 미사용’이라고 주장하지 않는다.

이 자료는 새로운 합성 생성 조건의 소규모 평가다. 새 현장·지역·임상 데이터 검증이 아니다. profile당 3환경의 기술통계만 보고하며 우월성·동등성·현실 발생빈도에 따른 전체 대표 평균을 추정하지 않는다. 이번 결과는 이후 연구의 미사용 검증 자료로 재사용할 수 없다.

## 지표와 분모

각 환경의 `report.json`은 다음을 기록한다.

| 항목 | 정의 |
|---|---|
| 미배정·미도착·미치료 | 최초 선정·최종 도착·치료 시작이 관측 종료까지 없는 환자 수. 우선순위 4/2/1별 별도 기록 |
| 제한 평균·p95·p99·최장 | 전체 고정 코호트. 미도착자는 관측 종료−발생시각을 포함. 선정은 문의 시작부터 별도 계산 |
| 실제 도착자 시간 | 도착한 환자만의 조건부 값과 분모를 별도로 표시 |
| 30/60/120분 이내 도착 | 전체 환자가 분모. 임상 골든타임이 아닌 실험상 시간 기준 |
| 개별 최대 악화·성공 상실 | 동일 case/patient ID로 H1−R0 및 H1−R1을 대응. 공통 도착자와 미도착을 포함한 제한값을 구분, 기존 선정·도착 성공 ID 상실도 보존 |
| 문의 부담 proxy | 문의 수·기관별 분포·최대 점유율·HHI. 실제 검토시간·의료진 피로 감소로 환산하지 않음 |
| 계산 | 결정 호출 wall time 평균·p95·p99·최장·합계, H1 호출 수·개선안 없이 기준해 유지한 호출 수. 환자 모의 시계에 계산 wall time을 더하지 않음 |
| 제약 위반 | 기존 독립 감사기가 저장된 수용·현재 자원·commit·사건 끝점 검사를 통과한 범위. 전체 자원 이력의 독립 재구성이나 최적성 증명은 아님 |
| 조건 변화 | 실제 `condition_update/redirect/transfer_search/resource_unavailable/notify` 사건 수와 자원 불일치 이송 분 기록 |

CP-SAT 분기가 없으므로 솔버 대체 해 비율은 `null`이다. H1의 기준해 유지는 시간 제한 솔버의 fallback과 다르다. 자원 갱신 지연은 엔진에서 현재 자원을 완전하게 관측해 미지원으로 기록했다. 실제 도로·병원 업무 시간·임상 결과도 `unavailable`로 명시한다.

## 실행·보존

```powershell
python -m unittest test_final_evaluation_20261030 -v
python -m simulation.final_evaluation_20261030 run --output outputs/final_evaluation_20261030/NEW-RUN
python -m simulation.final_evaluation_20261030 verify --output outputs/final_evaluation_20261030/NEW-RUN
```

동일 protocol/seed의 재현은 새 독립 검증 표본이 아니다. 최초 실행의 실패와 불리한 결과도 보존하고 선택적으로 재시도하지 않는다. 검증 명령은 정책을 다시 실행하지 않고 저장 raw를 재감사한다. 현재 감사기와 동결 소스가 다르면 거절한다.

`verify`는 새 `verification.json`을 한 번 생성하며 기존 영수증은 덮어쓰지 않는다. 반복 감사는 원본을 보존한 새 복사본에서 기존 영수증만 제외하고 수행한다. 이번 후속 재감사 복사본은 `.codex-build/final-readiness-20261030/holdout-reaudit-copy/`다.

최종 실행 경로는 `outputs/final_evaluation_20261030/holdout-v1/`이다. `execution-lock.json`, `seed-inventory.json`, `sources/`, 원 사건·계산 기록 `raw/*.json.gz`, `report.json`, `report.md`, `verification.json`을 함께 보존한다. 결과 수치와 좋은/나쁜/동일 사례는 해당 보고서가 원본이다.

새 테스트는 9개이며 12개 profile의 실제 엔진·감사, 입력 불변, 독립 사건 합계, seed 충돌·분리, 미도착 분모, 기존 출력 거절, raw 위변조 거절, 실패 캡슐 보존을 검사했다. 테스트 단위 실행은 최종 holdout 환자 수에 합산하지 않는다.
