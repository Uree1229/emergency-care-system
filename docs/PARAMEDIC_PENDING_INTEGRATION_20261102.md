## 1. 메인 입력·미확인 요청 복구

경로: `/paramedic/` · 구현: `paramedic-ui/main-recovery.mjs`, `app.js`.

- 서버·작업자·환자·초안 범위를 구분해 같은 탭의 `sessionStorage`에 체크포인트를 둡니다. 저장 전 문장, 항목 편집, 위치·동의 입력과 전송 결과가 불확실한 원래 요청을 보존합니다.
- HTTP 쓰기 전에 요청의 경로·메서드·본문·요청 ID·기대 버전을 저장합니다. 저장소 오류·용량 초과·다른 화면의 기록 변경을 감지하면 쓰기를 중단합니다.
- 새로고침 복원은 서버 조회부터 시작합니다. 원래 요청은 사용자가 **같은 요청 다시 시도**를 눌러 확인하며 자동 전송하지 않습니다. 기존 초안 조회 실패를 새 초안 생성으로 대체하지 않습니다.
- 서버 버전과 로컬 항목 편집의 기준 버전이 다르면 자동으로 덮어쓰지 않고 검토할 원본을 남깁니다. 환자를 실제로 바꿀 때는 이전 환자의 답변·검토 사유가 새 환자에 남지 않도록 초기화합니다.
- 최대 32개 기록, 기록당 4 MiB, 마지막 저장 후 12시간의 복원 제한입니다. 기한 경과는 자동 삭제·자동 재전송을 뜻하지 않습니다. 탭 종료·브라우저 데이터 삭제 이후 보존이나 다른 기기 복원을 보장하지 않습니다.

이것은 음성 메인 초안의 복구입니다. `/patient/` 수동 등록의 응답 유실 중복 가능성(D01)과 채팅 미확인 전송의 새로고침 복구(D02/H01)는 별도 작업입니다.

## 2. Quick 업무 화면의 800ms 명령 보류

경로: `/paramedic/quick-test.html` · [동작과 시험 기록](VOICE_COMMAND_GATE_20261031.md).

- 기존 낭독 스튜디오의 공통 `CommandCommitGate`를 Quick 업무 화면에도 연결했습니다. 기본은 **추가 말 확인 후 실행**이며, 명령 후보 이후 후속 인식 결과를 800ms 동안 확인합니다.
- 부정·인용·시간 설명이나 미확정 인식으로 후보가 취소·보류되면 이를 반영합니다. 명시적 버튼 종료는 다른 경로이며 항상 800ms를 기다린다는 뜻이 아닙니다.
- **버튼으로만 종료**는 음성 명령 동작을 실행하지 않는 관찰 정책입니다. 녹음 중 정책을 바꾸지 않습니다.
- 이 800ms는 인식 결과 수신 기준의 실험값입니다. 음향적 무음 측정·발화 종료 감지·최적 대기값·오탐 방지 보장이 아닙니다.
- 시험 이벤트 JSON은 직접 내려받습니다. 원문·임시 인식이 들어갈 수 있으며 DB나 복구 체크포인트에 자동 추가 보관하지 않습니다.
- 환자 등록, 병원 문의, 수용 확정과 목적지 변경에는 기존 명시 확인 절차를 유지합니다.

## 3. 원본·RNNoise 잡음 억제 비교

경로: `/paramedic/noise-compare.html` · 낭독 스튜디오 설정의 **다른 테스트 도구**에서도 이동합니다.

- 선택한 원본 녹음 하나를 공통 48kHz 모노 PCM으로 변환하고 A(공통 변환 원본)와 B(RNNoise 처리본)를 비교합니다. 원본 파일 바이트는 별도로 유지합니다.
- 로컬에 고정한 Jitsi RNNoise WASM을 사용합니다. 라이선스·원 출처·파일 해시는 `paramedic-ui/vendor/jitsi-rnnoise-wasm-0.2.1/`에 포함합니다. 런타임에 모델을 내려받지 않습니다.
- 재생·파일 선택·녹음은 사용자 조작으로 시작합니다. 비교 화면이 서버나 외부 STT에 오디오를 자동 전송하지 않으며 기존 브라우저 STT의 마이크 입력에 처리본을 자동 연결하지 않습니다.
- 사용자가 원본·A/B WAV·메타데이터·해시를 ZIP으로 내려받을 수 있습니다. 비교 결과는 메모리 상태이며 원래 연습 녹음 보관함을 변경하지 않습니다.
- 화면 이탈 시 진행 작업과 마이크를 종료합니다. 브라우저의 뒤로 가기 복귀 시에는 남아 있는 입력·결과를 조작할 수 있도록 복원하며 녹음·처리·재생을 자동 재개하지 않습니다.
- 합성 비교에서는 처리 후 인식이 나빠진 조건도 있었습니다. 기본 STT 전처리로 채택하지 않습니다. [기존 합성 결과와 한계](VOICE_RNNOISE_COMPARISON_20261031.md)를 함께 확인합니다.

선택형 오프라인 파일 인식 도구 `speech_eval/noise_pair_asr.py`와 별도 고정 의존성 `requirements-audio-asr-eval.txt`도 포함합니다. 이미 준비한 로컬 모델과 명시적으로 합성으로 표시한 16kHz PCM WAV 쌍이 필요합니다. 서버 실행에 추가 ASR 패키지 설치가 필요한 것은 아닙니다.
