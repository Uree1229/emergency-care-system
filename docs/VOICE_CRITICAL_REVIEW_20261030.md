# 중요 수치·부정 표현 복창 확인

대상은 대화형 `/paramedic/quick-test.html`이다. 서버가 저장한 구조화 초안으로 입력 내용을 점검한다. 임상적 정확성·응급도·의학적 정상 범위를 판단하는 기능이 아니다.

## 복창 대상과 표현

혈압(수축기·이완기 묶음), 맥박, 산소포화도, 체온, 호흡수, 혈당, 의식, 호흡, 증상 분류의 9개 그룹을 사용한다. 증상 그룹은 확인된 증상·없다고 확인한 증상·미확인 증상을 함께 보여 주고 함께 편집한다.

- 숫자에는 항목명과 단위를 붙인다. 양쪽 혈압을 구분해 읽는다.
- `absent`는 호흡 없음, `unknown`은 호흡 미확인으로 읽는다. 미확인을 정상이나 없음으로 바꾸지 않는다.
- 구토가 denied 목록에 있으면 구토 없음, 출혈이 uncertain 목록에 있으면 출혈 미확인으로 읽는다. 빈 목록으로 모든 증상이 없다고 추론하지 않는다.
- 재확인이 필요한 이전 관찰값은 현재 숫자로 읽지 않는다. 재확인 필요라고 표시하며, 그 상태에서는 맞아요 버튼을 사용할 수 없다.

저장 뒤 기본적으로 중요 항목을 확인 질문보다 먼저 한 번 읽는다. 마이크가 열려 있을 때 읽지 않고, 사용자가 녹음을 시작하면 기존 읽어주기를 취소한다. 설정에서 자동 복창을 끄거나 항목별 다시 듣기를 사용할 수 있다.

## 확인 상태

맞아요 버튼과 표시된 값 모두 맞아요 버튼은 먼저 같은 작성자의 초안을 GET으로 읽는다. ID·DRAFT 상태·환자 미연결·작성자·표시 버전·해당 값과 근거 서명이 모두 같아야 이 화면의 확인 상태를 바꾼다. 갱신·오류가 있으면 확인하지 않는다. 임상 `/confirm`, 환자 등록, 병원 문의는 호출하지 않는다.

확인 상태는 현재 화면 메모리에만 있다. 해당 그룹의 값·근거·재확인 상태가 바뀌면 무효화된다. 무관한 다른 항목 수정은 기존 확인을 지우지 않는다. 새로고침하면 모든 항목을 다시 확인한다. 수정창을 열거나 아니요로 답한 항목은 기존 확인을 지우며, 취소해도 다시 확인해야 한다. 추천 준비에서 계속하려면 표시된 중요 항목의 확인을 마쳐야 한다.

말로 확인은 해당 항목의 전용 버튼을 누른 뒤 최대 10초 동안 녹음한다. 확정 인식의 정확한 확인/수정 응답만 분류한다. 맞아요·네 등은 같은 GET 검증을 거쳐 확인하고, 아니요는 해당 항목 수정창을 연다. 네 맥박 130처럼 추가 정보가 포함된 문장은 일괄 확인하지 않고 미반영 검토용으로 보존한다. 일반 말하기·질문 답변의 예/아니요를 이 확인으로 가로채지 않는다.

## 항목 수정과 복구

선택한 그룹의 값만 구조화 PATCH `/api/voice/sessions/{id}/fields`로 보낸다. 증상 극성은 모순을 피하도록 세 목록을 원자적으로 편집한다. 숫자 공란은 unset, 의식·호흡의 미확인은 explicit unknown으로 구분한다. 미완성 숫자를 공란 삭제로 바꾸지 않는다. 같은 값도 명시적으로 재입력한 재확인 항목은 수정 요청에 포함해 이전 플래그를 해소할 수 있다.

성공 뒤 수정한 항목은 다시 복창 확인 대기가 된다. 오류·409에서는 입력한 수정안을 유지하며 최신 초안을 자동 덮어쓰지 않는다. 마지막 항목이 삭제되어도 편집기를 숨겨 사용자가 갇히지 않도록 취소 경로를 유지한다.

PATCH에도 기존 write-ahead 체크포인트를 적용한다. 원래 요청 ID·버전·본문과 correct 작업을 저장한 뒤 보내며, 응답 유실·재접속에는 명시적 같은 요청 재시도를 사용한다. 저장 전 편집안은 새로고침 후 직접 입력 검토칸으로 복원한다. PATCH 대기 중에는 구조화 원요청이 값을 보존하며 가상 음성 인식문을 만들지 않는다.

## 검증 범위

독립 기대값을 사용한 helper 시험, 실제 페이지·클라이언트·세션을 실행하는 모의 DOM 시험, 실제 production handler와 새 합성 SQLite를 연결하는 HTTP 시험을 분리한다. 숫자·부정·미확인 표현, 이전값 보호, 최신성 검사, 단일 항목 수정, 응답 유실·복원, 저장 공간 오류, 음성 확인 종료, 실제 DOM 입력 경계를 검증한다. 실제 마이크·현장 소음·STT 정확도·운영 DB·실제 환자·병원 전송은 시험에 사용하지 않는다.
