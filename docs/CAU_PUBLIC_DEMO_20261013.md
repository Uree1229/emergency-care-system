## 카카오 길찾기 연결 후속

중앙대 시연 좌표(37.5051, 126.9573)에서 중앙대학교병원까지 실제 길찾기 요청이 성공했고, 재시작한 서버의 기존 `CAU-E2E-001` 후보 조회에서도 20개 병원 모두 `travel.provider=kakao`를 확인했다. 해당 조회 시 중앙대학교병원은 도로 거리960m·예상5분이었다. 시간은 API 응답을 분 단위로 올림한 값이며, 호출 시각의 일반 자동차 경로 예상이다. 환자 화면은 성공한 결과를 ‘도로 이동 예상’으로 표시한다. 실패 시에는 기존처럼 거리 기반 추정으로 대체하며 두 출처를 구분한다.

재시작 전후와 후보 조회 전후의 전체22개 테이블 행 수·내용 해시가 동일했다. 기존 환자7건·문의47건·채팅5건·병원20곳·공공 관측306건을 보존했다. 새 환자·문의는 만들지 않았다. 검증 기록은 `.codex-build/kakao-live-20261014/probe-result.json`, `restart-result.json`, `live-verification.json`이다. 재시작 전 DB 백업도 같은 작업 폴더에 보관했다.

일반 `server.app`은 실행 프로세스의 환경변수를 읽는다. Windows 사용자 환경변수를 수정한 뒤에는 새 서버 프로세스에 명시적으로 전달하거나 새 터미널에서 실행해야 한다. 과거 `.codex-build/seoul-public-demo-20261013/start.py`와 `restart_after_reset.py`는 합성 시연을 위해 키를 제거하는 실행기이므로 이 연결을 재현할 때 사용하지 않는다. 아래의 ‘키가 없어 거리 기반 추정을 사용했다’는 문구는 2026-10-13 캡처 당시의 기록이다.

## 환자와 문의 범위

`CAU-SEOUL-DEMO-001`은22세, 교내 낙상 후 손목 통증·부종, 의식 명료·정상 호흡의 완전한 가상 사례다. 정형외과·응급병상1 요구도 시나리오 설정이고 중증도는 미평가다. 캠퍼스 좌표는 시연용이며 GPS 관측이 아니다. 본문은 `datasets/examples/cau_seoul_patient_001.json`.
