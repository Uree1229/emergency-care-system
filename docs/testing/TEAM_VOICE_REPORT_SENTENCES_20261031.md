# 팀원용 긴 환자 상태보고 낭독 세트

2026-10-31. 모든 내용은 **가상 환자의 합성 대본**이다. 실제 환자·개인정보·의료기관 연락처를 사용하지 않는다. 이 자료는 음성 인식·저장·수정 흐름을 시험하기 위한 것이며 진단·중증도·치료 방법의 기준이 아니다.

## 기본 진행

- **기본 세트는 REP-01~04**, 확장 세트는 REP-05~12다. 기본4개를 우선 수행한 뒤 여유가 있으면 확장한다.
- 각 대본은 **한 번에 이어서 읽는 한 문단**이다. 항목마다 녹음을 나누거나 질문에 하나씩 답하는 방식이 아니다. 화면에서 일반 입력/다른 내용 경로를 선택해 한 번 말하기를 시작하고, 본문을 끝까지 읽은 뒤 버튼으로 마친다.
- 본문에 실제 녹음 종료·새 환자·병원 추천 같은 제어 요청을 넣지 않았다. 본문을 읽을 때 제목·확인 항목·후속 발화를 같이 읽지 않는다.
- 증상 설명 중 앱 질문이 표시돼도 그 질문을 이 대본의 일부로 읽지 않는다. 조기 종료·무인식·오류·부분 저장은 그대로 기록한다. 성공처럼 보이게 원문을 고치거나 한 시도를 여러 번 읽은 결과로 바꾸지 않는다.
- 각 사례는 다른 가상 입력 기록에서 시작해 이전 사례 값이 섞이지 않게 한다. 기존 기록을 삭제하거나 실제 이송·수용·병원 문의를 시작하지 않는다.
- **후속 발화는 선택 확장**이다. 기본 긴 보고의 저장 결과를 확인한 뒤 한 발화씩 별도로 시험한다. 추가 관찰·입력 정정·저장값 조회를 구분한다.

## 결과를 확인하는 기준

아래 확인 항목은 작성자가 대본의 뜻을 기준으로 정한 **독립적인 점검 기준**이다. 현재 파서 출력으로 정답을 만들지 않았으며, 모든 항목의 추출·명령 성공을 실행 전에 보장하지 않는다.

1. 말하려던 대본과 브라우저에 실제로 표시된 인식문을 먼저 비교한다. 두 문장이 다르면 인식 단계 차이로 기록한다.
2. 인식문과 실제 저장 필드·메타데이터·경고를 비교한다. 인식문은 맞는데 값이 다르면 해석/저장 단계 차이로 기록한다.
3. `age`, `sex`, `consciousness`, `breathing`, 혈압·맥박·산소포화도·체온·호흡수·혈당 등 지원 구조화 항목을 확인한다. 증상은 현재 지원 사전의 범위 안에서 확인한다.
4. 알레르기·과거력·가족력·복용약·식사·보호자 설명은 **원문 맥락으로 남을 수 있다**. 별도 필드나 DB에 자동 저장된다고 가정하지 않는다. 알려진 혈압 하나가 추출됐다고 다른 문장까지 모두 처리됐다고 표시하지 않는다.
5. 미확인·미측정·없음을 구분한다. 값 없는 칸을0·정상·증상 없음으로 채우지 않는다. 서로 모순되는 수치는 현재 정답이 미확인인 시험이다.

수치 기준은 낭독 의도의 대조값이며 임상적 정상/비정상 판정이 아니다. 필드명이 화면에 그대로 보일 필요는 없으며 화면의 한국어 라벨과 대응해 확인한다.
