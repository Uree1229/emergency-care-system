# G2: 수용 인원 이득과 최상위 우선순위를 함께 보호하는 두 번째 후보

2026-10-28. G1은 기존 345환경에서 지연 142명 중 48명만 남기고 공통 도착 최대 지연을 100분에서 68분으로 줄였으나, 새 345환경에서 가중치4 환자 미배정이 원 H1보다 1명 증가했다. 일부 대기는 다른 환자로 옮겨갔고 기존 자료의 도착 cap 합도 증가했다. G1은 채택하지 않으며 소스·원문·결과를 보존한다.

## 새 규칙

현재 유효 수용 후보·현재 자원·알려진 이동시간만으로 caller 순서의 거리순 실행 가능 계획 B와 고정 원 H1 제안 H를 만든다. **H의 미배정 우선순위 합이 B보다 나쁘지 않고, (1) 수용 인원이 엄격히 늘거나, (2) 같은 인원에서 가중치4 환자를 더 많이 수용할 때 H를 쓴다. 그 외에는 B를 쓴다.** 가중치4는 실험의 최고 우선순위이며 실제 임상 판정을 뜻하지 않는다.

이는 같은 인원의 가중치1·2 교환은 억제하면서 최상위 우선순위 보호를 복구하는 G2 규칙이다. 원 H1 목적 전체를 항상 보존하는 규칙은 아니다. 현재 배치 조건은 미래의 전체 성공·우선순위·환자별 도착시간 비악화를 보장하지 않으므로 실제 전체 실행으로 확인한다. 원 H1 제안·B·실제 G2와 선택 사유를 별도 기록한다. 문의 3곳·최대2분 추가 대기·변경 알림, 고정 생성기, 부모 탐색 2,048회·10초 안전 상한을 유지한다.

## 사전 고정 평가

두 개의 이미 본 자료를 각각 회귀 자료로 쓴다. 첫 번째는 최초 비교의 345환경이며 원래 142명·고정 거리순 도착자1,587명과 모든 기존 조건을 재확인한다. 두 번째는 G1의 새 검증이었던 345환경이며 이제 개발에 사용한 알려진 자료다. 두 회귀는 각각 G2만 실행하고, SHA가 고정된 완전한 R0·R1·원 H1 벡터를 그대로 사용한다. 두 자료를 합쳐 효과를 주장하지 않는다.

두 회귀 모두 각 주 평가 층·각 스트레스 유형별 원 H1의 미배정 수·미배정 가중 합·가중치4 미배정 수를 늘리지 않아야 한다. 최초 회귀에서는 이전에 고정한 142명 지연 개선, 최대100분 미만, 고정 도착자 지연143명·제한 지연113분 미만 등의 조건도 모두 충족해야 한다. 다른 유형의 이득으로 손해를 상쇄하지 않는다. 기존 선정·도착 ID 상실과 신규 성공, 새 지연, 우선순위별 지연, 총 선정·도착 cap 합을 별도로 보고한다.

두 회귀의 원문 재감사와 모든 고정 조건이 통과하면 **아직 실행하지 않은 새 namespace `arrival_guard_priority_20261028_validation_v1`의 345환경**에서 R0·R1·원 H1·G2를 모두 새로 실행한다. 생성 분포는 그대로이며 main 각100환경과 stress 각5seed이다. 새 검증 결과를 보고 같은 후보를 조정하지 않는다.

미도착은 관측 종료 cap으로 남긴다. 임의의 환자별 best-of 참조는 만들지 않는다. 기존 부트스트랩 구현에서 H1 슬롯을 G2로 쓰는 명시적 투영만 통계 재현에 쓰며 원 H1 벡터는 따로 보존한다. 새 결과의 성공 보호 통과가 지연·도착 ID 전부 보존을 뜻하지는 않는다. 모든 시뮬레이션은 합성 데이터이며 실제 임상 효과나 전체 온라인 최적성을 주장하지 않는다.
