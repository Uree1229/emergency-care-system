# 낭독 스튜디오 · 음성 테스트 화면

기존 음성 명령 연습 화면을 **대본 읽기 → 녹음 → 결과 확인** 중심으로 정리했다. 기존 `command-practice.html` 주소를 그대로 사용한다. 환자 등록·병원 문의는 실행하지 않는 합성 대본 시험 화면이다.

## 실행

저장소 루트에서 다음 명령을 실행한다. Python 3 표준 라이브러리만 사용하며 DB나 API 키는 필요 없다.

```powershell
python paramedic-ui/preview.py
```

`http://127.0.0.1:18044/command-practice.html`을 연다. 이미 같은 포트로 실행 중이면 재실행하지 않고 새로고침한다. 별도 포트는 `--port 18084`로 지정할 수 있다. 서버는 이 PC의 loopback에만 바인딩한다.

공통 서버로 실행할 때는 기존 서버의 `/paramedic/command-practice.html` 주소를 사용한다. 마이크는 지원 브라우저(Chrome/Edge), 권한과 HTTPS 또는 localhost 환경이 필요하다. PC의 localhost 주소를 다른 사람에게 보내도 그 사람의 PC에서 이 서버에 연결되지는 않는다.

## 사용하는 순서

1. 처음에는 긴 대본 40개 중 첫 문장이 나온다. **다른 문장**으로 이동하거나 **문장 선택**에서 고른다. 고급 설정의 전체 유형은 합성 대본 96개다.
2. **녹음 시작**을 누르고 끝까지 읽은 뒤 같은 버튼으로 마친다. 원본 녹음 보관은 기본 선택이다. 정상·무인식·오류·중단 시도도 자동 보관한다.
3. 종료하면 인식 결과가 열린다. 원문은 수정하지 않고 보존한다. 대본대로 말한 것과 명령 의도가 맞는지 확인한 뒤 **정답 확인 후 다음**을 누른다. 다르게 말한 경우는 정답 검토에서 메모하거나 미확인으로 둔다.
4. **수집 기록**에서 기록 검토, ZIP·JSON·CSV 내보내기, JSON 합치기, 녹음 보관함 복구를 사용한다. ZIP은 실제 음성과 메타데이터를 함께 담고, JSON에는 음성이 없다.

휴대폰 크기에서는 녹음 조작부를 하단에 고정한다. 고급 설정에서 문장 필터·자유 발화·화자·장비·소음·마스크·마이크 거리 등 시험 조건을 조절한다. 자세한 대본/자료 수집 방식은 [기존 연습 안내](VOICE_COMMAND_PRACTICE_20261031.md), [팀원 테스트 안내](TEAM_VOICE_TEST_GUIDE_20261031.md)를 참고한다.

## 명령 처리 비교 설정

연습 화면의 기존 로컬 설정과 기록 형식을 함께 연결했다. 실제 환자·병원에 명령을 실행하지 않는다.

| 설정 | 의미 |
|---|---|
| 자동 종료 끔(기본) | 버튼으로 녹음을 마친다. 후보·가상 처리 이벤트만 기록한다. |
| 후속 문맥 기다림 | 자동 종료를 켠 경우 후보 뒤 추가 확정/임시 인식을 확인해 보류·취소·갱신한다. |
| 즉시 처리 · 비교용 | 첫 유효 확정 후보에서 종료를 요청하는 비교 기준이다. 뒤늦은 부정·인용을 놓칠 수 있다. |
| 실행 없이 관찰 | 자동 종료 체크와 관계없이 가상 결정만 기록한다. |

800ms는 **실험 설정값**이며 검증된 최적값이 아니다. STT 조각이 수신된 시간을 기록하며 실제 발음 시각이나 음향적 무음 시간을 측정하지 않는다. 더 늦게 들어오는 문맥은 놓칠 수 있다. 이벤트의 결정과 실제 녹음 종료는 구분한다.

`commandTrace`를 포함하는 시도는 schema 2로 저장한다. 기존 schema 1/2 자료도 읽으며, 원문·작성된 정답·출처를 유지한다. JSON/CSV/음성 ZIP과 녹음 보관함 복구에서도 해당 기록을 보존한다. 이 연습 정책을 다른 앱 화면에 일괄 적용하지 않았다.

## 저장 자료와 변경 범위

- 기존 localStorage 키 `paramedic.voice.command-practice.v1` 및 IndexedDB 이름/버전/녹음 저장소를 유지한다. UI 반영을 위해 자료를 초기화하지 않는다.
- 브라우저·기기·포트가 다르면 같은 저장 자료가 자동 공유되지 않는다. 새 수집 묶음 시작은 기존 백업·파일 확인 절차를 유지한다.
- 화면 모듈은 표시·설정 창·결과 패널을 담당한다. 실제 캡처·저장·정답 처리의 소유자는 기존 연습 모듈이다.
- Phosphor 공식 SVG 아이콘 및 Pretendard 폰트를 로컬 동봉했다. `paramedic-ui/studio-icons/LICENSE`, `FONT-LICENSE.txt` 참조. 실행 시 외부 CDN을 조회하지 않는다.
- 공통 서버에는 SVG/WOFF2 MIME 타입만 추가했다. 다른 서버·병원·구급대 화면의 작업은 포함하지 않는다.

## 검증

```powershell
node --test test_paramedic*.mjs
python -B -m unittest test_paramedic_studio_static -v
```

Node 검사는 실제 마이크 정확도가 아닌 인식 콜백·보류 정책·원문 보존·저장 실패·정답 독립성·음성 보관/내보내기를 검사한다. HTTP 검사는 임시 DB와 실제 handler로 HTML/CSS/MJS/SVG/WOFF2와 경로 이탈 차단을 확인한다. 실제 사람 음성·장치별 STT 품질은 별도로 시험해야 한다.
