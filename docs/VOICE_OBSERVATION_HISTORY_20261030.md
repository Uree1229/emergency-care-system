# 상태 관찰·수정 이력

`/paramedic/quick-test.html`의 `상태 관찰·수정 이력`에서 `이력 조회·새로고침`을 누른다. 마지막 변경만 보여주던 기존 표시를 보완해 여러 저장 버전의 이전 값·이후 값과 재확인 상태를 비교한다. 저장된 입력의 이력이며 임상 경과에 대한 자동 판단은 아니다.

## 범위와 표시

기존 `GET /api/voice/sessions/{sid}/history?actor_id=...`를 사용한다. 서버·DB 계약이나 팀 환자용·병원용 화면을 변경하지 않는다. 최근 최대 20건을 최신순으로 표시하고 전체 저장 이력 수를 함께 알린다. API는 전체 이력을 반환하므로 20건은 화면 표시 제한이며 네트워크 조회 제한이 아니다. 초안 버전 1의 초기 기존 정보는 변경 이력으로 새로 만들지 않는다. 발화 수와 변경 이력 수는 같지 않을 수 있다.

카드는 기록 시각·버전·변경 종류·이전 값과 이후 값을 보여준다. 기록 입력·관찰 변화 입력·입력 수정·되돌림·질문 답변을 구분한다. 입력 수정이나 되돌림을 새로운 측정·호전·악화로 표시하지 않는다. 기록 시각은 실제 측정 시각을 보장하지 않는다. 원본의 정밀한 시각은 검증에 유지하고 화면에는 사람이 읽는 KST 시각을 쓴다.

없음·미확인·미기록·삭제를 구분하며, 재확인이 필요한 이전 값을 현재 관찰로 표시하지 않는다. 값이 같아도 재확인 상태만 바뀐 이력을 남긴다. 기존 기록과 파생 항목도 직접 관찰과 구분한다. 원문·개인 메모·미반영 입력·알고리즘의 추천·임의 경고 문자열을 이력 카드의 사실로 넣지 않는다.

## 최신성과 환자 분리

최신 초안 GET → 변경 이력 GET → 최신 초안 GET 순서로 조회한다. 두 초안의 작성자·ID·DRAFT 상태·환자 미연결·버전·관찰 정보가 같을 때만 이력을 표시한다. 이력의 초안 ID, 버전·순서·연결 관계와 마지막 저장값도 대조한다. 조회 중 새 저장이 생기면 전체 미리보기를 버리고 명시적인 재조회를 안내한다.

조회 중 새 녹음·환자 전환·수정을 막고, 환자 번호·작성자·초안 ID·화면 세대·브라우저 보관본을 검사한다. 다른 탭의 보관본 변경이나 이전 환자의 콜백으로 이력을 표시하지 않는다. 로컬 저장본이 바뀌거나 저장 결과가 불확실하면 기존 이력도 비운다. 조회 실패 때 과거 카드를 최신 결과처럼 유지하지 않는다.

이력 조회 자체는 GET만 사용하며 초안 확인·환자 등록·병원 문의·전송을 수행하지 않는다. 서버에서 받은 이력을 브라우저 영구 저장소에 추가로 보관하지 않는다. 화면의 버전·조회 결과는 마지막 조회 시점을 뜻하며 실시간 자동 갱신을 뜻하지 않는다.

## 검증

고정 이력 모델의 독립 시험과 실제 페이지를 실행하는 모의 DOM 시험으로 값·분류·시간·누락·변경 없는 이력·손상·환자 전환·오래된 응답을 확인한다. 별도 새 SQLite와 실제 HTTP handler를 이용하는 통합 시험으로 여러 실제 음성 초안의 변경 이력을 조회한다. 합성 환자만 사용하며 실제 마이크·클라우드 STT·운영 DB·실제 병원 전송은 사용하지 않는다. 모의 인식기의 결과를 음성 인식 정확도 개선으로 해석하지 않는다.

최종 배포 후보의 Node 회귀 **1,277/1,277**, 실제 HTTP 통합 **15개 시나리오·104개 확인**을 통과했다. 새 관찰 `92 → 110`, 입력 수정 `110 → 96`, 되돌림 `96 → 110`을 모델과 실제 DOM에서 각각 확인했으며, 호흡 변경 줄의 미기록·미확인도 별도로 검사했다. 시험 DB의 환자·병원·문의 생성은 모두 0건이었다.

실제 브라우저에서는 합성 환자의 최초 입력·관찰 변화·입력 수정·이력 조회와 본문 스크롤을 확인했다. 실행 서버가 최종 소스 7개 파일과 같은 내용을 제공하는 것도 확인했다. 모의 DOM·합성 API 검증과 실제 브라우저의 화면 확인은 실제 마이크 인식 정확도 측정과 구분한다.

## 후속 후보

이번에는 관찰·수정 이력을 먼저 구현한다. 이후 후보는 통신 장애 시 저장 상태와 수동 입력 전환 안내, 서버에 보내기 전 음성 명령 동작을 확인하는 연습 기능이다. 각 기능은 별도 구현·검증 대상으로 진행한다.
