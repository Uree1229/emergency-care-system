# 병원 인계용 요약

대상은 `/paramedic/quick-test.html`이다. 현재 환자의 저장된 구조화 관찰을 고정 템플릿으로 정리한다. LLM 호출이나 진단·응급도 추정은 하지 않는다. 팀 환자용·병원용 화면과 배정 규칙은 변경하지 않는다.

## 사용

`병원 인계용 요약 · 입력 기반 초안`을 열고 `인계용 요약 만들기·새로고침`을 누른다. 생성만으로 복사·읽기·병원 전송을 실행하지 않는다. 내용을 검토한 뒤 복사하거나 읽어주기를 누른다. 클립보드가 거부되면 화면의 요약 텍스트를 선택해 수동으로 복사할 수 있게 안내하며 복사 성공으로 표시하지 않는다.

음성 `인계 요약해줘`, `병원 인계 요약해줘`, `인계용 요약해 주세요`는 첫 유효 명령 앞 내용을 기존 입력 문맥으로 저장한 뒤 미리보기를 연다. 명령 뒤 발화는 원환자의 미반영 목록에 남긴다. 명령만 있으면 빈 초안을 만들지 않는다. 일반 `요약해줘`는 기존 서버 검토 명령을 유지한다. 인용·보고·부정 표현과 항목별 복창 확인 녹음에서는 화면 명령을 실행하지 않는다. 저장 응답이 불확실하면 원래 요청 재시도 성공 후 한 번만 미리보기를 연다.

## 요약에 포함하는 정보

- 환자 번호·초안 버전·생성 시각과 저장된 연령·성별·발생 시각.
- 의식·호흡·증상 및 부정·불확실 증상, 혈압·맥박·산소포화도·체온·호흡수·혈당.
- 누락·재확인 대상·이전 관찰값과 확인이 필요한 항목.
- 마지막 기록의 이전 값과 현재 값. 관찰 변화·입력 수정·되돌림·질문 답변·기록 갱신을 구분하며 임상적 악화·호전을 추론하지 않는다.
- 이 화면의 복창 미확인 여부, 미반영 메모·저장 확인 대기 존재 여부.

없음·미확인·누락을 구분한다. 빈 증상 목록을 “증상 없음”으로 바꾸지 않는다. 현재 값이 미확인이면 이전 값을 현재 관찰 항목에 넣지 않고 이전 관찰로 분리한다. 서버의 관찰 메타 시각은 실제 측정 시각을 보장하지 않아 **관찰 입력 시각**으로 표시한다. 마지막 변경은 전체 임상 경과를 뜻하지 않는다.

원문·직접 입력·명령 뒤 미반영 문장·서버가 구조화하지 않은 내용·R1 등 알고리즘 제안은 사실 본문에서 제외한다. 미반영 내용은 존재 여부만 알린다. 복창 확인은 입력 내용에 대한 이 화면의 확인이며 의료적 검증이나 서버 확정이 아니다. 요약은 인계 전 사람이 검토하는 입력 기반 초안이다.

## 최신성 및 환자 분리

생성 시 GET으로 현재 작성자·초안 ID·DRAFT 상태·환자 미연결·최소 버전을 확인한다. 생성 이후 복사·읽기도 GET을 다시 수행해 같은 버전과 요약 원천 정보인 경우에만 진행한다. 바뀌었으면 미리보기를 비우고 명시적으로 재생성하도록 한다. 조회 실패 시 오래된 요약으로 대신 진행하지 않는다.

미리보기는 환자 번호·작성자·초안 ID·화면 세대에 연결한다. 환자 전환·로컬 미반영 내용 변경·복창 확인 상태 변경 시 무효화한다. 조회 중 다른 탭이 환자 목록을 바꾸거나, 이전 환자의 콜백이 늦게 도착하면 생성·복사·읽기를 막는다. 비동기 복사 완료 전에는 환자 전환·새 녹음을 막는다. 새 녹음을 시작하면 기존 안내 음성을 취소한다.

생성·복사·읽기는 초안 GET만 수행한다. 음성 명령 앞 본문을 저장하는 기존 초안 쓰기 외에 환자 등록·초안 임상 확정·병원 문의·병원 전송은 호출하지 않는다. 생성한 요약 텍스트를 localStorage에 추가 저장하지 않는다.

## 검증

고정 템플릿 독립 시험과 실제 페이지를 실행하는 모의 DOM 시험을 수행한다. 실제 handler·새 SQLite를 사용하는 HTTP 시험은 별도 합성 환자만 이용한다. 관찰/입력 수정 구분, 부정/미확인/이전 값, 미반영 원문 제외, 버전 변경, 조회 실패, 복사 거부, 복사 대기, 다른 환자 콜백, 명령 prefix/suffix 및 저장 응답 유실을 확인한다.

최종 배포 후보의 Node 회귀는 **1,162/1,162 통과**, 실제 HTTP 통합은 **18개 시나리오·120개 확인 통과**다. 시험 DB에는 음성 초안만 생성됐고 환자·병원·문의 생성과 임상 확정·전송 호출은 없었다. 시간 표시를 간결한 KST 형식으로 바꾼 뒤 동일 시나리오를 다시 확인했다.

통합 시험은 실제 마이크·클라우드 STT·운영 DB·OS 클립보드를 사용하지 않는다. DOM·인식기·음성 합성·클립보드는 모의 처리하므로 실제 브라우저 권한이나 음성 정확도 측정과 구분한다. 별도 실제 브라우저에서는 합성 환자 입력·새로고침 복원·요약 생성·본문 표시를 확인했다. 인계 요약을 펼쳤을 때 대화 영역이 작게 줄지 않도록 해당 상태에서 페이지를 자연스럽게 스크롤한다. 클립보드 권한은 실제 환경에 따라 거부될 수 있으며 수동 복사 안내로 대응한다. 이미 실행된 클립보드 쓰기는 외부 탭의 후속 변경으로 되돌릴 수 없다.
