환자 정보 입력

확인하지 못한 항목은 미확인으로 남겨주세요. 이 화면은 진단이나 중증도를 자동 판단하지 않습니다.

치료에 필요한 조건

증상으로 자동 추론하지 않습니다. 확인한 필요 진료 분야를 선택하세요. 미선택은 미확인입니다.

기본 진료 자리(ed_bed) 1단위를 요청합니다. 실제 치료 적합성은 병원이 확인합니다.

환자 위치 · 직접 입력

관측한 좌표를 입력합니다. GPS 자동 수집은 하지 않습니다.

병원 탐색 및 이송

위험 신호가 있습니다. 병원 회신을 기다리지 말고 119에 연락하세요.

병원 문의

병원의 수용 응답은 후보입니다. 목적지는 사람이 확정합니다.

후보 병원

조건과 이동시간을 비교한 목록이며 수용을 보장하지 않습니다.

문의 진행 상황

출발 · 조건 재확인

조건 변화는 현재 병원이 재확인합니다. 대체병원 문의는 병원의 조정 판단 후 시작하며 목적지는 자동 변경되지 않습니다.

현재 위치 관측 · 직접 입력

지금 관측한 좌표를 직접 전송합니다. GPS나 자동 추적이 아닙니다.

이송 종료

이송 대화방

시스템 · 이송자

병원은 목적지 확정 후 참여합니다. 채팅으로 수용·목적지 변경이 처리되지는 않습니다.
