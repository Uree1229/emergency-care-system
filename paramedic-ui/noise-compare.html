같은 음성, 소음 처리 A/B 비교

한 입력을 같은 48kHz 모노 PCM으로 바꾼 뒤 A는 그대로, B는 RNNoise로 처리합니다. 원본 파일은 바꾸지 않습니다.

소리가 더 깨끗해져도 인식 정확도가 좋아진다는 뜻은 아닙니다. 이 처리본은 현재 음성 인식기에 자동 전달되지 않습니다. 실제 환자정보가 없는 연습 자료를 사용하세요.

파일이나 연습 녹음을 골라 시작하세요. 자동 재생·서버 업로드는 하지 않습니다.

1. 같은 입력 한 개 선택

브라우저에 보관한 연습 녹음

같은 브라우저·주소의 연습 보관함을 읽기만 합니다. 기존 시도와 파일은 수정하지 않습니다.

한 번 녹음해서 두 경로로 비교

녹음 시작을 누른 경우에만 별도 마이크 권한을 요청합니다. 브라우저에 소음 억제·자동 이득·에코 제거 해제를 요청하지만 실제 해제를 보증하지 않습니다. STT는 실행하지 않습니다. 최대 180초·20MiB입니다.

선택한 입력 없음

먼저 재생 없이 길이를 확인해 180초 초과 입력을 거릅니다. 일부 녹음은 길이를 알려주지 않습니다. 위 선택은 그 경우 디코딩 메모리 사용을 허용하며, 디코딩 후에도 180초 초과 파일은 자르지 않고 거절합니다.

첫 처리에는 앱에 포함한 RNNoise 모듈을 읽습니다. 외부 CDN·앱 API·STT로 음성을 전송하지 않습니다. WAV는 브라우저 디코딩·모노화·48kHz 공통 변환을 거친 비교용 파일입니다.

2. 짝 조건과 독립 정답

참조문은 실제 녹음을 듣고 독립적으로 확인하세요.

참조문과 인식문은 자동 생성하지 않습니다. 실제 발화가 대본과 다르면 대본을 그대로 정답으로 쓰지 마세요. 다운로드 전에 개인정보를 확인하세요.

3. 재생·수동 인식문 비교

재생은 각 플레이어에서 직접 누르세요. A와 B는 같은 입력 PCM과 길이를 사용하며 녹음을 두 번 받아 비교하지 않습니다. 아래 수치는 신호 특성으로 인식률·의료 정확도가 아닙니다.
