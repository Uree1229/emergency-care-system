같은 탭의 임시 복구

같은 탭에서 입력과 미확인 요청을 이어갑니다.

임시 보관 범위·복구 한계

이 브라우저 원점의 현재 탭에 입력 원문·항목 편집·좌표·동의와 정확한 미확인 요청을 보관합니다. Azure 녹음 전송 요청에는 음원이 포함될 수 있으며 성공 또는 확정된 오류 후 미확인 요청에서 제거합니다. 저장본 하나당 최대 4 MiB, 마지막 저장 후 12시간이며 만료 후 복원하지 않습니다. 만료는 자동 복원만 차단하므로 저장 매체에서 지우려면 탭을 닫거나 사이트 데이터를 삭제하세요. 서버의 환자 전체 기록·로컬 WAV 다운로드·녹음 중 음성은 보관하지 않습니다. 새 탭·다른 기기·탭 종료 후 복원과 여러 탭 간 경합 방지는 보장하지 않습니다. 공용 기기에서는 사용 후 탭을 닫고 브라우저의 사이트 데이터를 지우세요.

저장한 초안으로 병원 추천 준비

초안 검토 → 화면에서 기록 확인 → 위치·동의 확인 → 환자 등록 버튼 → 병원 후보 확인

명령 뒤 문장은 아래 ‘인식문’에 복원되었습니다. 아직 초안에 반영되지 않았습니다. 직접 검토한 뒤 ‘문장 반영’을 누르거나 제외하세요.
